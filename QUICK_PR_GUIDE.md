# 📌 Quick Guide: Create PR on GitHub

## Step-by-Step Instructions

### Step 1: Navigate to GitHub
1. Go to: https://github.com/dhairyagothi/100_days_100_web_project
2. Click the **"Pull requests"** tab

### Step 2: Create New PR
1. Click **"New pull request"** button
2. Verify base branch: **Main** (target branch)
3. Verify compare branch: **feature/todo-search-filter** (your branch)
4. Click **"Create pull request"** button

### Step 3: Add PR Title
```
Fix: TO_DO_LIST search functionality and integrate Priority selector in Self-Improvement
```

### Step 4: Add PR Description
Copy the entire content from the **PR_SUMMARY.md** file in this directory.

### Step 5: Submit
Click **"Create pull request"** to finalize
