How It Works

Easy to use

Swipe left to skip a cafe. Swipe right to save it. You can also use the Skip and Save buttons if you do not want to swipe.

Extra Feature

Powered by OpenStreetMap

This app uses OpenStreetMap data (Overpass and Nominatim) to find nearby cafes, fill in address details, and load real cafe photos from Wikimedia/Wikipedia when metadata is available.
