🚀 Getting Started

  1. Fork & Clone
    git clone https://github.com/YOUR-USERNAME/100_days_100_web_project.git
  2. Add upstream
    git remote add upstream https://github.com/dhairyagothi/100_days_100_web_project.git
  3. Create branch
    git checkout -b feature/your-feature

➕ Adding New Projects

Add your project to index.js using this exact format: 

["Day XX", "Project Name", "./public/ProjectName/index.html", ["javascript", "css"], "Beginner"]
Difficulty must be:
"Beginner" "Intermediate" "Advanced"

📜 Standards & Policies

Code of Conduct

Be respectful, inclusive and welcoming to all contributors.

Security Policy

Report vulnerabilities responsibly through GitHub.

Project Standards
  • Semantic HTML
  • BEM CSS naming
  • ES6+ JavaScript
  • Run lint & format before PR
Issue & PR Guidelines

Clear descriptions, reproduction steps, and follow templates.

🎨 Documentation & Code Style

Semantic elements, proper indentation, alt texts, meaningful names.

BEM methodology, CSS variables, meaningful classes.

const/let, arrow functions, error handling, comments.
