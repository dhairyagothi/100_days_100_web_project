# Responsive Notes App

A clean and responsive Notes App built using HTML, CSS, and JavaScript.

## Features
- Create notes
- Edit notes
- Delete notes
- Search/filter notes
- Save notes using Local Storage
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
responsive-notes-app/
│── index.html
│── style.css
│── script.js
│── readme.md

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser

## Future Improvements
- Dark mode
- Note categories
- Pin important notes
- Voice notes support
