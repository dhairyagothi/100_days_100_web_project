# Image Carousel

## Description
A dynamic and responsive image carousel (slider) for showcasing multiple images or pieces of content in a single space. It features smooth transitions and intuitive navigation controls.

## Technologies Used
- HTML5
- CSS3 (Transitions & Flexbox)
- JavaScript (DOM Manipulation & Event Handling)

## Features
- **Smooth Transitions**: Sliding animations between images.
- **Navigation Controls**: Includes "Next" and "Previous" buttons for manual control.
- **Auto-Play Support**: Can be configured to automatically cycle through images.
- **Indicators**: Visual dots to show the current position in the carousel.
- **Responsive Layout**: Adapts to different container sizes and screen widths.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/carousal/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
carousal/
 ├── images/          # Images used in the slider
 ├── index.html       # Carousel structure
 ├── index.js         # Navigation and animation logic
 └── index.css        # Layout and transition styles
```
