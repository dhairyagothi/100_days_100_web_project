# 📔 Journal Platform

Journal Platform is a modern web application that allows users to create, organize, and manage personal journal entries in an intuitive interface. It provides a clean writing environment while demonstrating CRUD operations, responsive layouts, and front-end web development concepts.

---

## ✨ Features

- 📝 Create journal entries
- 📖 View saved journals
- ✏️ Edit existing entries
- 🗑️ Delete journal entries
- 📱 Fully responsive interface
- 🎨 Modern and clean UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Journal-Platform
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

## ▶️ Usage

1. Launch the application.

3. Save your journal.
4. Edit or delete entries whenever needed.
