# Password Generator

## Description
A highly customizable password generation tool that helps users create strong, secure passwords in seconds. By allowing users to specify length and character types, it ensures the generated passwords meet various security requirements for different platforms.

## Technologies Used
- HTML5
- CSS3 (Custom Properties & Responsive Design)
- JavaScript (Randomization & Clipboard API)

## Features
- **Customizable Length**: Generate passwords from 8 to 50+ characters.
- **Character Options**: Include uppercase, lowercase, numbers, and special symbols.
- **Strength Indicator**: Real-time feedback on the strength of the generated password.
- **One-Click Copy**: Copy the generated password to your clipboard instantly.
- **Responsive UI**: Fully optimized for mobile and desktop use.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Password_Generator/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Password_Generator/
```
