# CampusConnect - College Community Portal

CampusConnect is a premium, minimal, and lightweight Single Page Application (SPA) built to serve as a collegiate community dashboard. It is a clean-slate, frontend-only portal designed for users to enter their own data, which is persisted locally using the browser's `localStorage`.

## Features

- **Profile Customization**: Click the user profile section in the sidebar to dynamically change your name (default: **Sanjana Sharma**) and role/department.
- **Clubs Hub**: Create new clubs, follow/join clubs, and post announcements. Includes category filters.
- **Events Tracker**: Organize workshops, hackathons, cultural fests, and sports meets. Features RSVP toggles and dynamic counters.
- **Notes Sharing Repository**: Publish lecture handouts and reference manuals. Sort and filter notes by branch, semester, and course code.
- **Lost & Found Board**: Post lost and found notices with contact coordinates and last-seen locations.
- **Student Marketplace**: Sell textbooks, electronics, cycles, and other essentials directly within the campus. Includes category searching and quick contact triggers.
- **Dynamic Weekly Timetable**: View schedule presets or log custom class schedules dynamically.
- **Placement Updates Feed**: Share on-campus hiring updates, eligibility criteria (CGPA, branches), package details, application deadliness, and interview tips.
- **Dark Mode Support**: Toggle between clean light mode and premium dark mode in the top navigation bar.

## Technology Stack

- **Structure**: Semantic HTML5 with dynamic content template blocks.
- **Style**: Modern Vanilla CSS containing system variables, responsive layout breakpoints, and CSS-only empty state layouts.
- **Logic**: Vanilla JavaScript managing application state, routing, storage hooks, and form processing.
- **Persistence**: Safe `localStorage` syncing keeping your additions intact across browser reloads.
