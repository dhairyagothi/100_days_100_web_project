# Calculator App

## Description
A fully functional, sleek digital calculator for the web. It handles basic arithmetic operations with an intuitive interface, mimicking the look and feel of modern mobile calculators.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (String Evaluation & DOM Manipulation)

## Features
- **Basic Operations**: Addition, subtraction, multiplication, and division.
- **Clear & Delete**: Functions to clear the entire display or delete the last character.
- **Responsive UI**: Optimized for both desktop and mobile screens.
- **Keyboard Support**: Can be operated via on-screen buttons.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Calculator/`
3. Open `Calculator.html` in your web browser.

## Folder Structure
```text
Calculator/
 ├── Calculator.html  # Calculator structure
 ├── Calculator.css   # Styling for the keypad and display
 └── Calculator.js    # Calculation logic
```
