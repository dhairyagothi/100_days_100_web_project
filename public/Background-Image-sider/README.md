# Background Image Slider

## Description
A visually engaging full-page background image slider with smooth transition effects. This project allows users to navigate through a series of high-quality background images, ideal for landing pages or portfolio headers.

## Technologies Used
- HTML5
- CSS3 (Animations & Flexbox)
- JavaScript (Vanilla)

## Features
- **Full-Screen Layout**: Immersive background images that cover the entire viewport.
- **Smooth Transitions**: Elegant fade or slide effects between images.
- **Navigation Controls**: Includes arrow buttons for manual image switching.
- **Responsive Design**: Images scale correctly across different device sizes.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Background-Image-sider/`
3. Open `slider.html` in your web browser.

