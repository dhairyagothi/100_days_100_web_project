# Buttons UI Page

## Description
A showcase of modern, creative, and interactive button designs for web interfaces. This project demonstrates various CSS techniques like gradients, shadows, hover effects, and animations to create premium UI components.

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Flexbox, & Grid)

## Features
- **Diverse Styles**: Includes neon buttons, glassmorphism effects, 3D buttons, and animated gradients.
- **Hover Interactions**: Smooth micro-animations and color shifts on hover.
- **Responsive Grid**: Buttons are organized in a clean, responsive layout.
- **Copy-Paste Ready**: Designed as a library of reusable UI components.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/ButtonsUIPage/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
ButtonsUIPage/
 ├── index.html       # Gallery of button components
 └── style.css        # Advanced CSS styles for all button variants
```
