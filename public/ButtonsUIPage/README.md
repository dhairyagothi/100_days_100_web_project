# Button UI Collection

## Description
A fun collection of button designs and animations. Includes glow effects, gradient backgrounds, 3D styles, and various hover animations. Built with plain HTML, CSS, and JavaScript to explore different CSS techniques and make some cool interactive elements.

## Features
- Glow buttons with smooth hover effects
- Gradient buttons (Sunrise, Ocean, Purple Dream)
- 3D buttons with depth and shadow effects
- Outline buttons with fill animations
- Animation effects: ripple, slide, bounce, rotate, pulse, shake, glow-expand, split fill
- Responsive layout for mobile devices
- No frameworks or dependencies - just vanilla CSS

## Technologies Used
- HTML5
- CSS3
- JavaScript (basic)

## Installation/Setup
1. Clone or download the project
2. Open `index.html` in your browser
3. That's it!

## Usage
Just hover over the buttons to see the different effects. Click some of them too. The buttons are grouped by style so you can see how different CSS techniques create different effects.
