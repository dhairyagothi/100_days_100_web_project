# HCL Color Generator

## Description
A specialized color generation tool based on the HCL (Hue, Chroma, Luminance) color space. Unlike RGB or HEX, HCL is designed to be perceptually uniform, making it an excellent choice for creating accessible and visually balanced color palettes.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (HCL Color Conversions & DOM Manipulation)

## Features
- **Perceptual Uniformity**: Generates colors that are easier for the human eye to distinguish and balance.
- **Customizable Parameters**: Adjust Hue, Chroma, and Luminance to fine-tune your color selection.
- **Real-time Preview**: Displays the generated color instantly in a large preview box.
- **Copy-Paste Ready**: Provides HEX or RGB equivalent values for easy integration into designs.
- **Clean UI**: A focused and professional interface for designers and developers.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/HCL Color Generator/`
3. Open `index.html` in your web browser.
