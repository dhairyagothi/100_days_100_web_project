# Candy Crush Clone

## Description
A web-based clone of the popular match-three puzzle game, Candy Crush. Players swap colorful candies to create rows or columns of three or more matching candies, earning points and clearing the board.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Animations)
- JavaScript (Grid Logic & Drag-and-Drop)

## Features
- **Match-Three Logic**: Automatically detects and clears matches of three or more.
- **Drag-and-Drop**: Intuitive swapping of candies using mouse events.
- **Scoring System**: Points awarded for every successful match.
- **Dynamic Board**: New candies drop from the top to fill empty spaces.
- **Visual Effects**: Smooth transitions and animations for candy movements and clearing.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Candy_Crush_Game/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Candy_Crush_Game/

 ├── background.jpg   # Game background image

 ├── script.js        # Core game logic and matching algorithms
```
