# 🎓 StudySync

## 🚀 Overview

StudySync is a modern and responsive educational landing page built using **HTML, CSS, and JavaScript**.

The platform is designed to showcase online learning services, educational features, student testimonials, pricing plans, and newsletter subscriptions through a clean and interactive user interface.

StudySync focuses on delivering an engaging user experience with animations, dark mode support, smooth scrolling navigation, responsive layouts, and modern UI design.

# 🌙 Dark Mode

StudySync includes a modern dark mode experience.

### Features

* Cosmic dark background
* Glassmorphism cards
* Smooth theme transition
* Persistent user preference using LocalStorage

Toggle dark mode using the 🌙 button in the navigation bar.
