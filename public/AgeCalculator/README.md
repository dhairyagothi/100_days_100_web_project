# 🗓️ Age Calculator Component

A lightweight, precise client-side utility built for GSSoC that breaks down chronological age details and calculates milestones based on user parameters.

## ✨ Features Implemented
- **Precise Calculation:** Outputs strict differences down to the day, shifting dynamically according to varying monthly lengths.
- **Variable Targeting:** Supports setting custom static baseline endpoints (auto-defaults to the present day).
- **Countdown Module:** Pinpoints exactly how many days remain until the user's next anniversary.
- **Zodiac Sign Mapping:** Maps dates accurately to Astrological symbols (Bonus).
- **Time Transformations:** Converts full duration states into aggregated weeks and hours metric segments (Bonus).

## 📁 Structure Included
- `index.html` - Structured Semantic Layout markup.
- `style.css` - Clean layout design patterns optimized for desktop and mobile wrappers.
- `script.js` - Safe date math logic avoiding timestamp rounding errors.
