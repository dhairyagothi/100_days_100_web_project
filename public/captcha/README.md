# CAPTCHA Generator

## Description
A custom CAPTCHA generation tool for web forms. It generates random alphanumeric strings and displays them in a styled container to prevent automated bot submissions.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Glassmorphism)
- JavaScript (Random String Generation & Validation)

## Features
- **Random Generation**: Creates unique alphanumeric codes on every load or refresh.
- **Verification Logic**: Checks user input against the generated CAPTCHA.
- **Refresh Option**: Allows users to generate a new CAPTCHA if the current one is unreadable.
- **Styled UI**: Features a modern, clean interface with input validation feedback.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/captcha/`
3. Open `captcha.html` in your web browser.

## Folder Structure
```text
captcha/
 ├── captcha.html     # Main structure
 ├── captcha.js       # Generation and validation logic
 └── captcha.css      # Styling for the generator
```
