# 📅 Digital Planner

## About the Project

Digital Planner is a browser-based productivity application that helps users organize their daily tasks and activities in an interactive way.

The planner includes visual customization using stickers and audio support to create an engaging planning experience. Everything runs directly in the browser without requiring any installation.

## Features

- 📝 Create and manage planner entries
- 🎵 Audio support for interactive feedback
- 🌟 Decorative sticker functionality
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Clean user interface

## How to Use

1. Open the planner.
2. Add your tasks or notes.
3. Customize your planner using available stickers.
4. Use the audio controls if supported.
5. Continue organizing your daily schedule.

## How to Run Locally

1. Clone the repository

git clone https://github.com/your-username/100_days_100_web_project.git

2. Navigate to the project

cd public/Digital-Planner

3. Open index.html in your browser

or use Live Server in VS Code.
