# 🎯 Interview Sphere

Interview Sphere is a web-based platform designed to help users prepare for technical and non-technical interviews through organized resources, practice questions, and an intuitive interface. It serves as a centralized space for interview preparation and skill development.

---

## ✨ Features

- 📚 Interview preparation resources
- ❓ Practice interview questions
- 📝 Organized learning interface
- 🎯 User-friendly navigation
- 📱 Fully responsive design
- 🎨 Clean and modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd interview-sphere
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code
