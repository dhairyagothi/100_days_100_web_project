# 2D Car Racing Game

A simple and interactive 2D car racing game built using HTML, CSS, and JavaScript.

## Features
- Player-controlled car movement
- Random moving obstacles
- Collision detection
- Score tracking system
- Restart game functionality
- Smooth road animation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open index.html in browser
2. Use left and right arrow keys to move
3. Avoid obstacles and score points
