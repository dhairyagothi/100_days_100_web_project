# Compiler Workflow Visualizer

An interactive web-based educational tool that demonstrates how source code is processed through the different phases of a compiler. Users can enter simple code snippets and visualize the transformation of code through lexical analysis, syntax analysis, semantic analysis, intermediate code generation, optimization, and target code generation.

## 🚀 Features

### Core Features

* Source code input editor
* Interactive compiler workflow visualization
* Step-by-step phase execution
* Real-time output display
* Responsive user interface
* Modern dark-themed design

### Compiler Phases Covered

#### 1. Lexical Analysis

* Token generation
* Keyword identification
* Identifier recognition
* Operator detection
* Number classification

#### 2. Syntax Analysis

* Basic syntax validation
* Statement parsing visualization
* Code structure representation

#### 3. Semantic Analysis

* Variable declaration checks
* Type validation
* Scope verification
* Error detection simulation

#### 4. Intermediate Code Generation

* Three-address code representation
* Intermediate instruction visualization

#### 5. Code Optimization

* Optimization demonstrations
* Before-and-after code comparison
* Simplified optimization examples

#### 6. Target Code Generation

* Assembly-style output generation
* Machine-level representation simulation

## ▶️ Getting Started

### Prerequisites

A modern web browser such as:

* Google Chrome
* Mozilla Firefox
* Microsoft Edge
* Safari

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd Compiler-Workflow-Visualizer
```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## 🎯 How to Use

1. Enter a code snippet in the source code editor.
2. Click the **Visualize Compilation** button.
3. Observe the code passing through each compiler phase.
4. Review the generated outputs for every stage.
5. Learn how compilers transform source code into executable representations.

### Example Input

```c
int a = 5;
int b = 10;
int c = a + b;
```
