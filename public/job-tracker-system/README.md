# 💼 Job Tracker System

Job Tracker System is a web-based application designed to help users organize and monitor their job applications throughout the hiring process. It provides an intuitive interface to manage application details, track progress, and stay organized during job searches.

---

## ✨ Features

- 💼 Add new job applications
- 📋 View and manage all applications
- ✏️ Edit application details
- 🗑️ Delete applications
- 📊 Track application status
- 📱 Responsive design
- 🎨 Clean and modern interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd job-tracker-system
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Add a new job application.
3. Enter company, role, and application details.
4. Update the application status as it progresses.
5. Manage and review all applications from one place.
