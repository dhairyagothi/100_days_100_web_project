# Fireworks Click Effect

A fun interactive web project where colorful fireworks explode from wherever you click on the screen.

## Features

- Colorful particle burst on every click
- Smooth fade-out animation
- Randomized direction, size, and color for every particle

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open index.html in a web browser
2. Click anywhere on the screen and enjoy!
