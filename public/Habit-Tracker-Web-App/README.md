# ✨ Professional Habit Tracker

A sleek, modern, and high-performance web application designed to help you build better routines and maintain consistent streaks with a premium glassmorphic interface.

![Habit Tracker Preview](https://via.placeholder.com/800x450/1a1a1a/ffffff?text=Habit+Tracker+Preview)

## 🚀 Features

- **🔥 Streak Tracking**: Keep track of your daily wins with an automated streak counter.
- **🌓 Dynamic Theme**: Switch between dark and light modes with a single click.
- **📊 Real-time Stats**: Instant feedback on total habits, completion count, and daily progress percentage.
- **💡 Daily Motivation**: Start your day right with inspiring quotes.
- **🌊 Modern UI**: Glassmorphic cards, smooth animations, and a responsive layout powered by Poppins typography.
- **💾 Persistent Storage**: Your habits and streaks are automatically saved to `localStorage`.
- **✅ Easy Management**: Add, mark, and delete habits with a clean, intuitive interface.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for accessibility and SEO.
- **Vanilla CSS3**: Custom properties (variables), Flexbox, Grid, and Glassmorphism effects.
- **JavaScript (ES6+)**: Dynamic DOM manipulation and state management.
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins) for premium typography.

## 🏁 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SadhanaShree5/100_days_100_web_project.git
   ```
2. **Navigate to the project**:
   ```bash
   cd public/Habit-Tracker-Web-App
   ```
3. **Open the app**:
   Simply open `index.html` in any modern web browser or use a live server.
