# 🧠 Quiz App

Quiz App is an interactive web application that allows users to answer multiple-choice questions, receive instant feedback, and view their final score. It is designed to demonstrate JavaScript fundamentals such as DOM manipulation, event handling, and quiz logic in a clean and responsive interface.

---

## ✨ Features

- ❓ Multiple-choice quiz questions
- ✅ Instant answer validation
- 📊 Final score calculation
- 🔄 Restart quiz functionality
- 📱 Responsive design
- 🎨 Simple and intuitive user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Quiz-App
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Start the quiz.
3. Select the correct answer for each question.
4. Complete all questions.
5. View your final score and restart if desired.
