# 🎨 Image Particle Engine

Image Particle Engine is an interactive JavaScript particle visualization project that converts uploaded images into animated particles. Users can interact with particles using the mouse, customize particle behavior, apply different physics presets, and export the generated artwork.

---

## ✨ Features

- 🖼️ Upload custom images
- 🎯 Convert images into particle systems
- 🖱️ Interactive mouse repulsion effect
- ⚡ Multiple particle behavior presets
- 💥 Particle explosion animation
- 🔄 Reset particle positions
- 📥 Save particle artwork as PNG
- 🎚️ Adjustable particle resolution
- 🔵 Adjustable particle size
- 🎯 Adjustable mouse interaction radius
- 📱 Responsive canvas rendering

## ▶️ Usage

1. Launch the application.
2. Upload an image.
3. Adjust particle resolution.
4. Change particle radius.
5. Modify mouse interaction radius.
6. Select a particle physics preset.
7. Interact with particles using the mouse.
8. Use **Explode** to scatter particles.
9. Click **Reset** to restore the original image.
10. Save the current frame as a PNG image.

---

## 🎮 Controls

| Control | Description |
|----------|-------------|
| Upload Image | Load a custom image |
| Resolution | Controls particle density |
| Particle Radius | Changes particle size |
| Mouse Radius | Controls interaction strength |
| Explode | Applies explosion effect |
| Reset | Restores original particle layout |
| Save | Downloads current canvas frame |
