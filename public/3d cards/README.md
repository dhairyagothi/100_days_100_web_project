# 3D Rotating Cards

## Description
A visually stunning CSS-only 3D card effect that showcases rotating card elements with image content. This project demonstrates advanced CSS 3D transforms and perspective properties to create an immersive, interactive experience.

## Technologies Used
- HTML5
- CSS3 (3D Transforms & Perspective)

## Features
- **3D Rotation Effect**: Cards rotate in 3D space using CSS transforms.
- **Smooth Transitions**: Clean, animated transitions between card states.
- **Image Integration**: Cards display images with polished styling.
- **Pure CSS**: No JavaScript required — entirely built with CSS.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/3d cards/`
3. Open `index.html` in your web browser.

## Folder Structure

```text
3d cards/
 ├── Images/
 ├── index.html
 └── style.css
```
