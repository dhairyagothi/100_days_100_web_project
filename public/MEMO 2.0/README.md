# 🧠 MEMO 2.0

MEMO 2.0 is an interactive browser-based memory game designed to improve concentration and short-term memory through engaging gameplay. Players are challenged to remember patterns, sequences, or matching elements while enjoying a smooth and responsive gaming experience.

---

## ✨ Features

- 🧠 Interactive memory-based gameplay
- 🎮 Engaging and intuitive interface
- ⚡ Smooth animations and transitions
- 🔄 Restart and replay functionality
- 📱 Fully responsive design
- 🎨 Modern and visually appealing UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ Gameplay

1. Launch the game.
2. Observe the displayed cards or sequence.
3. Memorize the positions or order.
4. Interact with the game to reproduce the correct pattern.
5. Progress through increasingly challenging levels.
