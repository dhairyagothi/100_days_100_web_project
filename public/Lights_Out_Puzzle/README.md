# Lights Out Puzzle

## Description
A classic logic puzzle game where the objective is to switch all the lights off. Clicking a light toggles it and its adjacent neighbors. This project implements the game with a grid-based interface.

## Technologies Used
- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (Game Logic)

## Features
- **Interactive Grid**: A 5x5 grid of lights.
- **Puzzle Mechanics**: Toggling one light affects the surrounding lights (top, bottom, left, right).
- **Win Detection**: Notifies the player when all lights are successfully turned off.
- **Responsive Design**: Adapts the grid size for different devices.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Lights_Out_Puzzle/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Lights_Out_Puzzle/
 ├── index.html       # Game structure
 ├── script.js        # Logic for toggling lights and win condition
 └── styles.css       # Visual styling for the grid and lights
```
