# Netflix - Watch TV Shows & Movies Online

A high-fidelity 1:1 responsive replica of the Netflix streaming platform, packed cleanly and compressed into exactly **three core files: HTML, CSS, and vanilla JS**, featuring full interactivity, profile storage, custom video play, synchronized subtitles, and search filter lists.

---

## 🎬 Live Interactive Features

- **Profile Selector Screen ("Who's watching?")**: landing page experience featuring iconic Netflix smiley-avatar designs with fully editable profile names and individual user accounts.
- **Dynamic Billboard Header Banner**: A high-impact cinematic billboard showcasing the stranger things lead title with play triggers and informative specification popups.
- **Responsive Media Rows & Carousels**: Staggered scroll categories with smooth-sliding left/right chevron vectors and tactile hover zoom scale adjustments.
- **Interactive Player Console**: Plays beautiful streaming preview clips with progress sliders, mute shortkeys, volume indicators, and synchronized text captions representing real subtitle mechanics.
- **Dynamic Content Discovery & Search**: Fully integrated Search panel that updates card results instantly as you type titles, genres, actors, or keywords.
- **Personalized "My List" Persistence**: Profile-specific item tracking that saves added shows safely to the local database, surviving web-browser reloads.
- **Deep Info Dialog**: Contextual popup displaying match percentages, releasing years, content classifications, creators lists, full cast credits, and custom "More like this" recommendations matrices.

---

## 📦 File Architecture

This application has been compressed and unified into exactly **three core application files**:

1. **HTML Layer (`index.html`)**: Defines the global layout skeleton with the official title **"Netflix - Watch TV Shows Online, Watch Movies Online"**, preloads Google Web Fonts, and mounts the compiled scripts.
2. **CSS Layer (`style.css`)**: Implements the dark theater-mode canvas (`#141414`), tailwind theme overrides, customized horizontal scroll hides, cinematic radial shadows, and hardware-accelerated card transitions.
3. **JS Logic Layer (`script.js`)**: Powers the full client-side state machine, mock cinematic databases, horizontal scrolling row bounds calculations, search filters, modal toggles, subtitle synchronizations, and profile cache storage managers.

## 🚀 Quick Setup & Direct Execution

### Complete Local Installation:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Boot the Hot-Reload Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build optimized bundles for static deployment**:
   ```bash
   npm run build
   ```
