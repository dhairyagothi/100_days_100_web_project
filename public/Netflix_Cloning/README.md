# Netflix Clone

## Description
A visually accurate frontend clone of the Netflix landing page. This project focuses on replicating the modern, dark-themed UI of Netflix, including its signature hero section, responsive grid layouts, and interactive components.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- Google Fonts (Poppins, Martel Sans)

## Features
- **Hero Section**: High-impact banner with a darkened background image and clear call-to-action.
- **Responsive Navigation**: Clean navbar with logo and sign-in functionality.
- **Feature Showcases**: Multi-section layout with alternating text and media (images/videos).
- **Interactive FAQ**: Styled accordion-style FAQ boxes for user inquiries.
- **Membership Form**: Integrated email subscription input fields.
- **Grid Footer**: Comprehensive, responsive multi-column footer with categorized links.
- **Fully Responsive**: Optimized for various screen sizes using CSS media queries.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Netflix_Cloning/`
3. Open `Index.html` in your web browser.
