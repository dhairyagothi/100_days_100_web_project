# 🎬 Netflix Cloning

Netflix Cloning is a responsive front-end web application inspired by the official Netflix landing page. It recreates the modern streaming platform interface with visually appealing layouts, responsive sections, and interactive UI components, making it an excellent project for learning responsive web design.

---

## ✨ Features

- 🎬 Netflix-inspired homepage
- 📺 Hero banner section
- 🎞️ Movie and TV show categories
- 📱 Fully responsive layout
- 🎨 Modern user interface
- ⚡ Smooth scrolling and animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Netflix_Cloning
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code
