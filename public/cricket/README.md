# Cricket Game

## Description
A fun and simple browser-based cricket game where players can test their reflexes. The game features realistic images of bats, balls, and stadiums to create an engaging experience for cricket fans.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Animations)
- JavaScript (Random Logic & Scoring)

## Features
- **Interactive Gameplay**: Choose between Bat, Ball, or Wicket and see if you win or lose against the computer.
- **Scoring System**: Tracks the player's wins, losses, and ties.
- **Visual Feedback**: Displays the outcome of each round with corresponding images and messages.
- **Themed UI**: Uses cricket-related assets like stadium backgrounds and equipment images.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/cricket/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
cricket/
 ├── *.jpeg/webp      # Cricket assets (bat, ball, stadium, wickets)
 ├── index.html       # Game structure
 ├── script.js        # Game logic and score tracking
 └── style.css        # Theme styling
```
