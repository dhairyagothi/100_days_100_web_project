Pathfinding Visualizer

An interactive tool to visualize graph traversal algorithms

Supported Algorithms

Dijkstra's Algorithm

The father of pathfinding algorithms; guarantees the shortest path.

A* Search

Arguably the best pathfinding algorithm; uses heuristics to guarantee the shortest path much faster than Dijkstra's Algorithm.

Breadth-First Search

A great algorithm; guarantees the shortest path on an unweighted graph.

How to use

  • Drag the Start () and End () nodes to move them.
  • Click and drag on empty grid cells to draw walls.
  • Select an algorithm from the top toolbar and hit "Visualize".
