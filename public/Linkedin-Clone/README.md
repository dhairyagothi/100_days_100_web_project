# LinkedIn Clone

## Description
A high-fidelity frontend replica of the LinkedIn homepage. This project focuses on mimicking the complex layout of the professional social networking site, including the navigation bar, user profile card, feed, and sidebar widgets.

## Technologies Used
- HTML5
- CSS3 (Flexbox & CSS Grid)

## Features
- **Professional Navbar**: Includes search bar, navigation icons (Home, My Network, Jobs, etc.), and profile dropdown.
- **Three-Column Layout**: Mimics the desktop view of LinkedIn with a left profile summary, middle content feed, and right news/recommendations widget.
- **Feed Interaction**: Styled posts with like, comment, share, and send buttons.
- **Responsive Design**: Adjusts layout for smaller screen sizes.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Linkedin-Clone/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Linkedin-Clone/

 ├── index.html       # Main structure and content
 └── style.css        # Layout and component styling
```
