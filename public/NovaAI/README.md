# 🚀 NovaAI - Virtual Startup Pitch Website

NovaAI is a futuristic startup pitch website built using only HTML, CSS, and JavaScript.

It delivers a premium startup-style landing page experience with smooth animations, glassmorphism UI, interactive sections, animated metrics, and modern visual effects.

---

## 🌟 Features

- ⚡ Modern futuristic startup UI
- 🎨 Glassmorphism design effects
- ✨ Animated custom cursor
- 📈 Animated metrics & counters
- 🚀 Smooth scroll reveal animations
- 🌌 Ambient glowing background effects
- 📱 Fully responsive layout
- 🎯 Interactive hover effects
- 💰 Funding progress section
- 👩‍💻 Team showcase section
- 🧠 Vision & mission storytelling
- 🔗 Back to Home button integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome Icons
