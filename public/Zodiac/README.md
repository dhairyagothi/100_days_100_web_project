# 🌠 Overview

**ORIONIS – Cosmic Mapper & Constellation Guide** is an interactive astronomy-inspired web application that transforms your browser into a digital planetarium.

Explore beautifully animated constellations, adjust the brightness of the night sky using a light pollution simulator, zoom and pan across space, and discover fascinating mythology behind famous star formations.

Everything is rendered using the HTML5 Canvas API, providing smooth animations and an engaging educational experience.

# 🎯 How to Use

1. Open the application in your browser.
2. Adjust the **Light Pollution** slider to control the number of visible stars.
3. Drag the canvas to explore different regions of the sky.
4. Use the mouse wheel to zoom in and out.
5. Hover over constellations to view their names and regions.
6. Click a constellation to read its mythology and background information.
