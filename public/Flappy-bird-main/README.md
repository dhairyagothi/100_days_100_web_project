# Flappy Bird Clone

## Description
A browser-based clone of the addictive "Flappy Bird" game. Players control a bird, trying to fly between rows of green pipes without hitting them. This project uses the HTML5 Canvas API for rendering and implements core game physics.

## Technologies Used
- HTML5 (Canvas API)
- CSS3
- JavaScript (Game Loop & Collision Detection)

## Features
- **Smooth Gameplay**: Implements gravity and jumping physics for the bird.
- **Infinite Scrolling**: Obstacles (pipes) are generated continuously as the player progresses.
- **Score Tracking**: Displays the player's current score in real-time.
- **Classic Assets**: Features the original-style bird, pipes, and background images.
- **Game Over State**: Detects collisions and allows for instant restarts.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Flappy-bird-main/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Flappy-bird-main/
 ├── index.html       # Game container and core logic
 └── *.png            # Game assets (bird, pipes, background)
```
