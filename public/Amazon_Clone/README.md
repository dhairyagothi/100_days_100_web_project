# Amazon Clone

## Description
A frontend replica of the Amazon e-commerce homepage, featuring a responsive product grid, navigation bar, hero banner, and footer. This project demonstrates modern CSS layout techniques for building complex e-commerce interfaces.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)

## Features
- **Product Grid**: Eight product category cards with images and call-to-action links.
- **Hero Banner**: Full-width promotional banner image.
- **Navigation Bar**: Amazon-style navbar with logo, search bar, and account links.
- **Responsive Design**: Adapts to various screen sizes.
- **Footer Section**: Multi-column footer mimicking Amazon's layout.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Amazon_Clone/`
3. Open `index.html` in your web browser.
