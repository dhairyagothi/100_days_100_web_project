# Blog Page (Organic Farming)

## Description
A modern and responsive blog post interface designed for a clean reading experience. Built with Tailwind CSS, this project features a high-quality article layout with interactive engagement tools, including a real-time commenting system and interactive social actions.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- JavaScript (Vanilla)
- Lucide/Heroicons (SVG Icons)

## Features
- **Responsive Design**: Seamlessly transitions between a single-column mobile view and a two-column desktop layout.
- **Interactive Social Actions**: Dynamic "Like" and "Bookmark" buttons with state changes.
- **Commenting System**: Functional interface to add and display user comments.
- **Optimized Typography**: Focused on readability with well-spaced text and clear headings.
- **Scrollable Content**: The main article area is scrollable while maintaining the visibility of the engagement sidebar on desktop.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Blog Page/`
3. Open `index.html` in your web browser.
