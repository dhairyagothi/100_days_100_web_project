# 🧠 Flashcard Quiz App

An interactive Flashcard Quiz application built with **HTML, CSS, and JavaScript** to help students learn and revise concepts through categorized flashcards.

![Preview](preview.png)

---

## ✨ Features

- 📚 Multiple Categories
  - Web Development
  - DBMS
  - Computer Networks
  - Operating Systems
  - Data Structures & Algorithms

- 🎯 Interactive Quiz Mode
- ✅ Instant Answer Checking
- 👀 Show Answer Option
- ➕ Add New Flashcards
- ✏️ Edit Existing Flashcards
- 🗑️ Delete Flashcards
- 💾 Local Storage Support
- 📱 Responsive Design

## 🎮 How to Use

1. Open the application.
2. Select a subject.
3. Read the question.
4. Type your answer.
5. Click **Check Answer**.
6. If needed, click **Show Answer**.
7. Navigate using **Previous** and **Next**.
8. Add, edit, or delete flashcards anytime.
