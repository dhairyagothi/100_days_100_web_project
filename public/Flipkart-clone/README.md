# Flipkart Clone

A responsive Flipkart-style storefront clone with a top navigation bar, category shortcuts, a hero slider, branded promo cards, and a signup page.

## Features

- Flipkart-inspired navbar and search box
- Category shortcuts for common shopping sections
- Auto-sliding hero banner with manual controls
- Branded spotlight cards and promotional blocks
- Separate signup page for account flow

## How to Use

1. Open the main page in a browser.
2. Browse categories or use the search bar.
3. Use the hero controls to move through featured promotions.
4. Open the signup page if you want to explore the auth screen.

## Files

- `index.html` - Homepage layout
- `style.css` - Main page styling
- `nav.css` - Navbar styles
- `script.js` - Hero slider and interaction behavior
- `signup.html` - Signup page

## Notes

- The page uses external Google Fonts and Font Awesome.
- Product and banner imagery is bundled in the folder.
