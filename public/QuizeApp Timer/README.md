# Quiz Application with Timer

## Description
A comprehensive quiz application designed to test knowledge under pressure. It features a diverse range of questions across multiple categories, an integrated countdown timer for each question, and instant feedback on performance.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (Timer Logic & Dynamic Question Rendering)

## Features
- **Countdown Timer**: Each question must be answered within a specified time limit, adding an extra layer of challenge.
- **Multiple Categories**: Supports a wide variety of topics for a diverse testing experience.
- **Instant Scoring**: Tracks and displays your score immediately as you progress through the quiz.
- **Visual Feedback**: Highlights correct and incorrect answers with clear color indicators.
- **Final Result Summary**: Provides a detailed summary of your performance at the end of the quiz.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/QuizeApp Timer/`
3. Open `index1.html` in your web browser.

