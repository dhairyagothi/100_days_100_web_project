MODERN GMAIL NODEMAILER PROJECT

STEPS TO EXECUTE

1. Install Node.js
https://nodejs.org

2. Open terminal in project folder

3. Run:
npm install

4. Enable Gmail 2FA

5. Generate Gmail App Password:
https://myaccount.google.com/apppasswords

6. Open server.js

Replace:
YOUR_GMAIL@gmail.com
YOUR_APP_PASSWORD

with your Gmail and App Password

7. Start backend:
npm start

8. Open index.html using VS Code Live Server

9. Fill form and test email sending

IMPORTANT:
- Backend must run before frontend
- Do NOT open HTML by double click
