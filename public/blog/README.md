# Personal Blog Template

## Description
A modern, multi-page blog template designed for personal use or small publications. It features a clean landing page, detailed blog post views, and a responsive design that emphasizes content readability.

## Technologies Used
- HTML5
- CSS3 (Custom properties & Flexbox)
- JavaScript (Vanilla)

## Features
- **Dynamic Content Loading**: Smooth transitions between the main feed and individual posts.
- **Responsive Layout**: Adapts perfectly to mobile, tablet, and desktop views.
- **Modern Typography**: Carefully selected fonts for an optimal reading experience.
- **Interactive Elements**: Hover effects and sleek navigation menus.
- **Search Integration**: Built-in search functionality to find specific articles.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/blog/`
3. Open `main.html` for the home feed or `blog.html` for the post layout.

## Folder Structure

```text
blog/

 ├── blog.html
```
