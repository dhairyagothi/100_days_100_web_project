# 🧠 Emotion Color Generator

A creative web app that converts human emotions into dynamic color palettes and backgrounds.

## ✨ Features
- Emotion-based color generation
- Animated background changes
- Copy color palette
- Reset functionality
- Simple UI with glassmorphism

## 🎨 Supported Emotions
- Happy
- Sad
- Angry
- Calm
- Default fallback

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 💡 Concept
This project maps human emotions to visual color psychology.
