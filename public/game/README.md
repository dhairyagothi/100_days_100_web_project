# 🐞 Catch The Insect

An interactive browser-based insect catching game built using HTML, CSS, and JavaScript.

## 🎮 About The Game

Catch as many insects as possible before they multiply and take over the screen. Select your favorite insect and test your reflexes in this fun and challenging game.

## ✨ Features

- Interactive gameplay
- Multiple insect choices
  - Fly
  - Mosquito
  - Spider
  - Roach
- Live score tracking
- Time counter
- Animated insects
- Responsive design
- Back to Home navigation button

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Play

1. Click **Play Game**
2. Choose an insect
3. Click insects as they appear on the screen
4. Increase your score by catching insects
5. Try to survive as the game becomes more difficult
