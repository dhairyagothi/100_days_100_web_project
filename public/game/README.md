# Catch The Insect

A small browser game where players choose an insect, watch it appear on screen, and click as many as they can before the timer runs out.

## Features

- Simple start and select screens
- Insect selection before gameplay
- Random insect spawning on the play area
- Score tracking with a time counter
- End-state message once the score gets high enough

## How to Play

1. Click **Play Game**.
2. Select an insect to hunt.
3. Catch the insects as they appear.
4. Keep going to raise your score.

## Files

- `index.html` - Game UI and layout
- `style.css` - Visual styling
- `script.js` - Game logic and spawning behavior

## Notes

- The game uses external image assets for the insect sprites.
- The play area adapts to the current window size.
