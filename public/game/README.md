# 🐞 Catch The Insect

## Description
A retro-themed, fast-paced browser game where players must catch randomly appearing insects. This version features a dark, immersive background and a playful "impossible challenge" vibe, testing the player's speed and precision.

## Technologies Used
- HTML5
- CSS3 (Keyframe Animations & Pixel Art Style)
- JavaScript (Dynamic Sprite Generation & Game Loop)

## Features
- **Insect Selection**: Choose between a Fly, Mosquito, Spider, or Roach to hunt.
- **Increasing Difficulty**: More insects appear as your score increases, making the game progressively harder.
- **Animated Sprites**: Insects feature a floating animation to add to the visual appeal.
- **Real-time Metrics**: Tracks gameplay time and current score.
- **Retro Aesthetic**: Uses the 'Press Start 2P' font and high-contrast visuals for a classic arcade feel.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/game/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
game/
 ├── index.html       # Game structure and embedded styles
 ├── script.js        # Game logic and insect spawning
 └── style.css        # Layout and screen transitions
```
