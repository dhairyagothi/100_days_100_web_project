# Greenhouse - Comprehensive Plant Website

## Description
A full-featured, multi-section website for a plant nursery or botanical shop. This project includes sections for product categories, customer testimonials, and care guides, providing a complete digital experience for plant lovers.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (for scroll-spy and navigation)

## Features
- **Extensive Product Catalog**: Categorized sections for indoor, outdoor, and exotic plants.
- **Testimonials Section**: Features customer reviews and feedback for social proof.
- **Care Guides**: Informational snippets on how to maintain different types of plants.
- **Responsive Navigation**: A sticky navbar with smooth scrolling to various sections.
- **Rich Visual Content**: Utilizes a variety of images to create an immersive green environment.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Plants Website/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Plants Website/
 ├── images/          # Extensive library of plant and background images
 ├── index.html       # Multi-section website structure
 ├── script.js        # Scrolling and navigation logic
 └── style.css        # Comprehensive layout and theme styling
```
