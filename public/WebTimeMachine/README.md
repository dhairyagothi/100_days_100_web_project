# 🕰️ Web Design Time Machine

## 📝 Description
The **Web Design Time Machine** is an interactive, visual project that demonstrates the evolution of web design over the past few decades. By dragging a simple slider ranging from 1995 to the 2020s, the webpage dynamically updates its CSS to match the design trends of that specific era. 

It serves as a fun nostalgia trip and a practical demonstration of how powerful CSS is when separated from HTML structure!

## ✨ Features
- **Interactive Timeline Slider:** Users can drag the slider to change the current "Year".
- **Dynamic CSS Swapping:** JavaScript listens to the slider and updates data attributes to completely overhaul the page's styling without changing the HTML structure.
- **Distinct Design Eras:**
  - **1990s:** Classic gray backgrounds, out-set borders, and Times New Roman fonts (Web 1.0).
  - **2000s:** Glossy gradients, heavy drop shadows, and rounded Web 2.0 aesthetics.
  - **2010s:** Minimalist flat design, clean sans-serif typography, and solid colors.
  - **2020s:** Modern glassmorphism, dark mode themes, and smooth transitions.
- **Fully Responsive:** Adapts beautifully to mobile and desktop screens.
