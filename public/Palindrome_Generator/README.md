# Palindrome Checker

## Description
A practical utility tool that checks whether a given string (word, phrase, or number) is a palindrome. It filters out non-alphanumeric characters and case differences to provide an accurate assessment, making it a fun and educational tool for word enthusiasts.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (String Manipulation & Regex)

## Features
- **Instant Validation**: Quickly determines if the input is a palindrome upon submission.
- **Robust Logic**: Uses regular expressions to ignore spaces, punctuation, and casing.
- **Interactive UI**: Provides clear visual feedback on whether the input is or isn't a palindrome.
- **Clean Design**: Features a focused and easy-to-use interface.
- **Educational**: A great example of basic string algorithms in JavaScript.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Palindrome_Generator/`
3. Open `index.html` in your web browser.
