# ClimaCode 2.0

## Description
A sophisticated weather application with a unique rotary interface and dynamic environmental themes. It provides a visual and interactive way to check weather conditions, featuring smooth transitions between different times of day and weather states.

## Technologies Used
- HTML5
- CSS3 (Conic Gradients & 3D Transitions)
- JavaScript (Animation Frames & DOM Manipulation)

## Features
- **Rotary Interface**: Click to rotate through different weather states.
- **Dynamic Themes**: Visual changes for Sunny, Sunset, Moonlit, Cloudy, Stormy, and Snowy conditions.
- **Temperature Conversion**: Seamlessly toggle between Celsius and Fahrenheit with eased animations.
- **Interactive Elements**: Features a rotary dial and loading bars for a premium feel.
- **Advanced CSS**: Utilizes complex conic gradients and layered animations for depth.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/ClimaCode 2.0/`
3. Open `index.html` in your web browser.
