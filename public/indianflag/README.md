# Jay Hind - Indian Flag & Quotes

## Description
An interactive tribute to India, featuring a digital Indian flag and a collection of inspiring patriotic quotes from famous freedom fighters. The project includes a background video and smooth quote navigation.

## Technologies Used
- HTML5
- CSS3 (Animations & Flexbox)
- JavaScript (DOM Manipulation)

## Features
- **Digital Indian Flag**: A CSS-based representation of the Indian flag.
- **Patriotic Quotes**: A curated list of quotes from freedom fighters like Subhas Chandra Bose, Bhagat Singh, and Mahatma Gandhi.
- **Quote Navigation**: Previous and next buttons to cycle through quotes and associated images.
- **Immersive Background**: A patriotic background video to enhance the user experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/indianflag/`
3. Open `flag.html` in your web browser.

## Folder Structure
```text
indianflag/
 ├── img/             # Images of freedom fighters and Ashoka Chakra
 ├── flag.css         # Styles for flag and layout
 └── flag.html        # Main HTML file with script
```
