# <div align="center">Self-Improvement Dashboard</div>

## 🚀 Personal Growth OS — Track, Build, Achieve

A modern, feature-rich self-improvement dashboard that helps you set and track goals, build positive habits, earn achievements, follow structured learning paths, and get personalized recommendations — all in a stunning dark-themed interface.

---

### ✨ Features

| Module | Description |
|--------|-------------|
| 📊 **Dashboard** | Centralized overview with stats, daily challenge, recommendations, and activity heatmap |
| 🎯 **Goals** | Create, categorize, prioritize, and track goals with milestones and progress rings |
| 🔥 **Habits** | Daily/weekly habit tracking with streaks, calendar heatmap, and consistency scores |
| 📈 **Analytics** | SVG charts for goal completion, habit consistency, yearly activity, and engagement |
| 🏆 **Achievements** | 20 unlockable badges with confetti celebrations and a points-based leveling system |
| 📚 **Learning Paths** | 5 structured development paths (Productivity, Mindfulness, Fitness, Creativity, Leadership) |
| 🤖 **AI Recommendations** | Rule-based personalized suggestions that adapt to your progress and patterns |
| ⚡ **Daily Challenges** | Fresh challenges every day with rewards and completion tracking |
| 🔔 **Notifications** | In-app toast notifications and configurable reminders |

---

### 🛠️ Tech Stack

- **HTML5** — Semantic markup with ARIA accessibility
- **CSS3** — Custom properties, glassmorphism, animations, responsive grid
- **Vanilla JavaScript** — Modular IIFE architecture, localStorage persistence
- **SVG Charts** — Inline SVG for all data visualizations (no external libraries)
- **Google Fonts** — Inter typeface

---

### 🎨 Design

- Dark theme by default with light theme toggle
- Glassmorphism card design
- Smooth micro-animations and transitions
- Fully responsive (mobile, tablet, desktop)
- WCAG accessible (keyboard nav, focus indicators, screen reader support)

---

### 📂 Files

| File | Purpose |
|------|---------|
| `index.html` | SPA structure with all views |
| `style.css` | Complete design system (~1800 lines) |
| `script.js` | All application logic (~2500 lines) |
| `responsive.css` | Redirects to style.css (responsive rules integrated) |
