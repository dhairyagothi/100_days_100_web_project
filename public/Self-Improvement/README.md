# Self-Improvement Dashboard

## Description
A comprehensive web dashboard designed to track personal growth and daily tasks. It features sections for goal setting, habit tracking, and progress visualization, aimed at helping users maintain focus on their self-improvement journey.

## Technologies Used
- HTML5
- CSS3 (Responsive Design & Animations)
- JavaScript (Data Handling & DOM Updates)

## Features
- **Task Management**: Add, edit, and check off daily self-improvement tasks.
- **Progress Tracking**: Visual indicators of daily and weekly achievements.
- **Responsive Layout**: Includes a dedicated `responsive.css` for optimal mobile viewing.
- **Engaging UI**: Uses images and styling to create an inspiring environment.
- **Interactive Elements**: Smooth transitions and interactive buttons for a better user experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Self-Improvement/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Self-Improvement/
 ├── *.jpg            # Background and thematic images
 ├── index.html       # Dashboard layout
 ├── script.js        # Task tracking logic
 ├── style.css        # Main visual styling
 └── responsive.css   # Mobile-specific layout rules
```
