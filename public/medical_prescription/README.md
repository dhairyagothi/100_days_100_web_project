# Prescripto

Prescripto is a browser-based prescription management app for patients, doctors, and caregivers. It helps users create accounts, manage prescriptions, track daily medicine doses, and review patient adherence using a simple local web app.

## Features
- Role-based registration and login for patients, doctors, and caregivers
- Demo accounts for quick testing
- Patient dashboard with profile and medical information
- Doctor dashboard with professional profile details
- Caregiver dashboard linked to an assigned patient
- Prescription creation with multiple medicines and dose timings
- Daily medicine schedule with taken/missed dose tracking
- Prescription history and patient adherence reports
- Data stored locally in the browser using localStorage

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open `index.html` in a web browser
2. Use the demo account option or register a new account
3. Enjoy the project!
