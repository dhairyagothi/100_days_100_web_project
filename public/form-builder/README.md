# 🚀 Advanced Form Builder

![HTML](https://img.shields.io/badge/HTML5-Structure-orange)
![CSS](https://img.shields.io/badge/CSS3-Styling-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-Logic-yellow)
![License](https://img.shields.io/badge/License-MIT-green)

An interactive **Advanced Form Builder** that enables users to create custom HTML forms dynamically. Users can add different field types, preview the form in real time, and generate ready-to-use HTML code without manually writing markup.

---

## ✨ Features

- 📝 Create form fields dynamically
- 📧 Multiple input types
  - Text
  - Email
  - Password
  - Number
  - Select
  - Checkbox
  - Radio Buttons
  - Textarea
- ✅ Required field support
- 👀 Live form preview
- ⚡ Generate HTML instantly
- 📋 Copy generated HTML with one click
- 📱 Fully responsive interface
- 🎨 Clean and modern design
- 🔧 Easy customization

## ⚙ Installation

Clone the repository.

```bash
git clone https://github.com/your-username/AdvancedFormBuilder.git
```

Go into the project.

```bash
cd AdvancedFormBuilder
```

Open the project.

```bash
index.html
```

or simply open **index.html** in your browser.

---

## 🚀 Usage

1. Open the application.
2. Choose a field type.
3. Enter the field label.
4. Add options for Select, Checkbox, or Radio fields.
5. Mark fields as Required if needed.
6. Preview the form instantly.
7. Click **Generate HTML**.
8. Copy the generated code and use it in your project.
