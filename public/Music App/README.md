# Music Player

## Description
A sophisticated browser-based music player designed for a seamless listening experience. It features a modern interface with support for multiple themes, track queuing, and detailed track information including artist and album data.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (Icons)
- SVG (Custom Interface Elements)

## Features
- **Dynamic Track Queue**: View and select songs from a built-in playlist.
- **Playback Controls**: Standard play, pause, next, and previous functionality.
- **Progress Tracking**: Real-time progress bar with current time and total duration display.
- **Theme Customization**: Switch between different visual themes to match your mood.
- **Volume Management**: Precise volume control with a quick-mute option.
- **Detailed Metadata**: Displays artist name, album name, and dynamic cover art for every track.
- **Blur Effect Background**: Establishes a premium look by using a blurred version of the cover art as the background.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Music App/`
3. Open `index.html` in your web browser.
