# 💳 Razorpay Payment Integration

This project demonstrates how to integrate the **Razorpay Payment Gateway** into a web application. It provides a simple and responsive payment interface that can be used as a starting point for e-commerce websites, donation platforms, subscription services, and other payment-based applications.

---

## ✨ Features

- 💳 Razorpay Checkout Integration
- 🔒 Secure payment processing
- ⚡ Fast payment experience
- 📱 Responsive user interface
- 🎨 Clean and modern design
- 🛒 Easy integration into existing projects

```bash

```

```bash

```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## 💳 Razorpay Setup

1. Create a Razorpay account.
2. Generate your **Test API Keys** from the Razorpay Dashboard.
3. Replace the placeholder API key inside the project.

Example:

```javascript
key: "YOUR_RAZORPAY_KEY_ID"
```

4. Run the application locally.

---

## ▶️ Usage

1. Launch the application.
2. Click the payment button.
3. Complete the Razorpay checkout flow.
4. Verify successful payment.
