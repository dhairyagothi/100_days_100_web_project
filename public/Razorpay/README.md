# Razorpay UI Clone

## Description
A high-fidelity frontend clone of the Razorpay landing page. This project meticulously recreates the modern and professional aesthetic of India's leading payments solution, showcasing advanced layout techniques and a clean, trust-oriented design.

## Technologies Used
- HTML5
- Tailwind CSS (for comprehensive styling)
- JavaScript (for navigation and interactive elements)

## Features
- **Accurate Branding**: Uses Razorpay's signature color palette, typography, and iconography.
- **Complex Hero Section**: Recreates the dynamic and engaging introduction area.
- **Feature Showcases**: Grid-based layouts highlighting various payment products and services.
- **Responsive Navigation**: A detailed navbar with dropdowns and CTA buttons.
- **Modern Aesthetic**: Utilizes subtle shadows, gradients, and a clear information hierarchy.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Razorpay/`
3. If you have Tailwind CSS installed, you can modify `tailwind.config.js` and rebuild.
4. Otherwise, simply open `index.html` in your web browser to see the pre-built version.

## Folder Structure
```text
Razorpay/
 ├── img/             # Comprehensive library of brand icons and product images
 ├── index.html       # Landing page structure
 ├── output.css       # Compiled Tailwind CSS
 ├── package.json     # Project dependencies (Tailwind)
 └── tailwind.config.js # Custom Tailwind configurations
```
