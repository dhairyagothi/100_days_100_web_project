# ⚡ Typing Battle Arena

A futuristic cyberpunk-inspired typing speed game built using **HTML, CSS, and Vanilla JavaScript**.

Typing Battle Arena transforms typing practice into a competitive experience with **multiple game modes, combo streaks, live stats, XP progression, ranks, and a local leaderboard**.

---

## 🎮 Features

### ⚔️ Multiple Game Modes

* **Sprint Mode** — 30-second fast-paced typing challenge
* **Ranked Mode** — 60-second competitive mode
* **Survival Mode** — limited lives, mistakes reduce health
* **Zen Mode** — unlimited typing with no timer

### 📊 Real-Time Stats

* Live **WPM (Words Per Minute)**
* Accuracy tracking
* Combo streak counter
* Highest streak tracker
* Character count
* Mistake counter

### 🏆 XP & Rank System

Progress through typing ranks:

🥉 Bronze Typist
🥈 Silver Typist
🥇 Gold Typist
💎 Platinum Typist
🔥 Diamond Typist
👑 Master Typist

Earn XP based on:

* Typing speed
* Accuracy
* Combo streaks

### 📈 Local Leaderboard

Track your best performances locally using browser storage.

Leaderboard sorting:

* WPM
* Accuracy
* Streak

### ⚙️ Settings Panel

Customize gameplay with:

* Difficulty selection
* Font size control
* Typing feedback toggle
* Sound toggle
* Cursor visibility toggle

### 📱 Responsive Design

Fully responsive UI optimized for:

* Desktop
* Tablet
* Mobile devices

## 🚀 How to Run

1. Clone the repository or download the project

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd TypingBattleArena
```

3. Open:

```text
index.html
```

in your browser

No installation or dependencies required.

---

## 🎯 Gameplay

1. Enter your username/callsign
2. Select a game mode
3. Click **ENTER BATTLE**
4. Complete the typing challenge
5. Track stats and climb the ranks
