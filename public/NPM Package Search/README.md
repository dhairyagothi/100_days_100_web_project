# NPM Package Search

## Description
A dedicated search tool for exploring the vast NPM (Node Package Manager) ecosystem. It allows developers to quickly find packages, view descriptions, and access essential information directly from the browser using the official NPM registry API.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Layout)
- JavaScript (Fetch API & NPM Registry API)

## Features
- **Instant Search**: Fetches package data from the NPM registry as you type.
- **Detailed Results**: Displays package names, versions, descriptions, and authors.
- **Direct Links**: Includes links to the official NPM page for each discovered package.
- **Clean UI**: A focused and professional interface designed for productivity.
- **Responsive Design**: Works seamlessly across all devices.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/NPM Package Search/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
NPM Package Search/
 ├── index.html       # Search interface structure
 ├── script.js        # API integration and result rendering
 └── styles.css       # Layout and visual design
```
