# Dev Environment Generator

![Dev Environment Generator Preview](./screenshot-placeholder.png)

A premium, modern SaaS-style developer utility built using only **HTML, CSS, and Vanilla JavaScript**.

## Project Overview

The Dev Environment Generator helps developers instantly generate a recommended development setup based on their preferred tech stack. Instead of manually looking up best practices, folder structures, and boilerplate installation commands, this tool provides everything in a single, copyable, and downloadable output panel.

## Features

- **Frontend Only:** Built entirely without a backend or APIs. The recommendation logic is powered by a predefined JavaScript object database.
- **Dynamic Framework Selection:** Options change automatically based on the selected Project Type (Frontend, Backend, Full Stack, Mobile).
- **Premium UI:** Glassmorphism aesthetic, dark/light theme options, glowing animations, and a responsive grid layout.
- **Terminal Output Style:** Results are formatted inside a sleek terminal-like window for easy reading.
- **Clipboard API:** One-click copy for the generated setup instructions.
- **Download as Text File:** Generate and download a `setup.txt` file directly from the browser without a backend.
- **LocalStorage Persistence:** Remembers user preferences, tool selections, generated counts, and theme choices across page reloads.

## Tech Stack

- **HTML5:** Semantic structure and form elements.
- **CSS3:** Custom variables, flexbox, grid, glassmorphism (`backdrop-filter`), keyframe animations.
- **Vanilla JavaScript (ES6+):** DOM manipulation, dynamic event handling, `localStorage`, `Clipboard API`, `Blob API` for downloads.

## Installation Steps & How to Run

Because this project is built entirely with static web technologies, there is no build process or backend server required to run it locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/dev-environment-generator.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd dev-environment-generator
   ```

3. **Run the application:**
   Simply open the `index.html` file in any modern web browser.
   Alternatively, you can use an extension like VS Code Live Server to launch it locally.
