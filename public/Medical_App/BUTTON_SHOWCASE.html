✅ Best Practices

DO

  • Use primary buttons for main CTAs
  • Include icon + text for clarity
  • Add aria-labels to icon-only buttons
  • Maintain minimum 44px height
  • Use full-width in forms
  • Test keyboard navigation

DON'T

  • ✕ Use color alone to convey meaning
  • ✕ Remove focus indicators
  • ✕ Mix multiple sizes on same row
  • ✕ Create buttons looking like links
  • ✕ Forget responsive behavior
