# MedConsult (Medical Consultation Platform)

## Description
MedConsult is a web application designed to facilitate communication between local practitioners and specialized medical professionals. It allows doctors to submit patient conditions and request expert consultations, track the status of these requests, and maintain a history of specialist responses.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- **Consultation Requests**: Form for doctors to input patient details and search for specific specialist types.
- **Real-time Status Tracking**: View the current state of consultation requests.
- **Specialist Interface**: Dedicated section for specialists to provide medical suggestions based on consultation IDs.
- **Consultation History**: Persistent list of past consultations and suggestions.
- **Feedback System**: Integrated feedback mechanism for users to rate the consultation experience.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Medical_App/`
3. Open `index.html` in your web browser.
