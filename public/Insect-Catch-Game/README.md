# Catch The Insect Game

## Description
A fun and interactive browser-based game where players select their "favorite" insect and try to catch as many as possible as they appear randomly on the screen. The game features a timer and a scoring system.

## Technologies Used
- HTML5
- CSS3 (Transitions & Animations)
- JavaScript (Game Logic & DOM Manipulation)

## Features
- **Insect Selection**: Choose between a Fly, Mosquito, Spider, or Roach.
- **Dynamic Gameplay**: Insects appear at random locations and increase in number as you play.
- **Timer & Score**: Real-time tracking of gameplay duration and score.
- **Responsive Screens**: Smooth transitions between the start screen, selection screen, and game container.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Insect-Catch-Game/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Insect-Catch-Game/
 ├── index.html       # Main game structure
 ├── script.js        # Game logic and insect generation
 └── style.css        # Game styles and animations
```
