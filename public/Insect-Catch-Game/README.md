# 🐞 Insect Catch Game

Insect Catch Game is a fun and interactive browser-based arcade game where players catch insects as quickly as possible to increase their score. As the game progresses, the difficulty increases, providing an engaging and challenging experience.

---

## ✨ Features

- 🐞 Interactive insect-catching gameplay
- 🎮 Simple and intuitive controls
- ⏱️ Live timer and score tracking
- 📈 Increasing game difficulty
- 📱 Fully responsive design
- 🎨 Attractive and engaging interface

---


Run locally

- Open `index.html` in your browser

---

## ▶️ Gameplay

1. Launch the game.
2. Select an insect to begin.
3. Click on insects as they appear on the screen.
4. Earn points by catching insects quickly.
5. Continue playing as the game becomes more challenging.
