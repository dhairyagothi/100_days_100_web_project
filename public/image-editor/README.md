# 🖼️ Image Editor

Image Editor is a browser-based image editing application that allows users to upload, edit, and enhance images directly in the browser. It provides essential editing tools through an intuitive and responsive interface without requiring any external software.

---

## ✨ Features

- 🖼️ Upload images
- ✂️ Crop images
- 🔄 Rotate images
- ↔️ Flip horizontally & vertically
- 🌈 Adjust brightness
- 🎨 Adjust saturation
- 🌑 Adjust contrast
- ⚫ Apply grayscale effect
- 💾 Download edited image
- ⚡ Real-time image preview
- 📱 Responsive interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Canvas API

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate into the project

```bash
cd image-editor
```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Open the application.
2. Upload an image.
3. Apply the desired editing tools.
4. Preview the changes in real time.
5. Download the edited image.

---

## 🎛️ Editing Tools

| Tool | Description |
|------|-------------|
| Upload | Load an image |
| Crop | Crop selected area |
| Rotate | Rotate image |
| Flip | Flip horizontally/vertically |
| Brightness | Adjust image brightness |
| Contrast | Adjust image contrast |
| Saturation | Adjust color saturation |
| Grayscale | Convert image to grayscale |
| Download | Save edited image |
