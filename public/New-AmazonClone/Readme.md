# New Amazon Clone

A modern, interactive, and responsive Amazon-inspired e-commerce website built using HTML5, CSS3, and JavaScript. This project recreates the core interface of an online shopping platform with a structured navigation system, product categories, promotional sections, search controls, side navigation, and an interactive shopping cart interface.

## Overview

New Amazon Clone is a front-end e-commerce project inspired by the Amazon India shopping experience.

The project demonstrates how fundamental web technologies can be combined to create a complete shopping-style interface. It contains multiple sections commonly found on e-commerce websites, including navigation, search, product categories, promotional content, side navigation, and a shopping cart interface.

The project is designed primarily for learning and practicing front-end web development concepts.

---

## Features

### Navigation System

The website provides a multi-section navigation interface containing:

- Amazon-style logo
- Delivery location
- Product category selector
- Search input
- Search button
- Language selector
- Account and Lists section
- Returns and Orders section
- Shopping cart access

### Category Navigation

The secondary navigation bar provides quick access to:

- Amazon miniTV
- Best Sellers
- Today's Deals
- Mobiles
- Prime
- Customer Service
- Electronics
- Fashion
- Sell

### Side Navigation

An interactive navigation panel provides categorized options such as:

- Trending
- Best Sellers
- New Releases
- Movers and Shakers
- Echo & Alexa
- Fire TV
- Kindle E-Readers & eBooks
- Audible Audiobooks
- Amazon Prime Video
- Amazon Prime Music
- Mobiles and Computers
- TV, Appliances and Electronics
- Men's Fashion
- Women's Fashion

### Product Categories

The homepage contains multiple product sections covering:

- Fashion & Clothing
- Daily Essentials
- Home Essentials
- Gadgets & Mobiles
- Beauty & Wellness
- Pet Care
- Kids & Toys
- Women's Fashion

Each section includes a product image and a navigation option for additional content.

### Shopping Cart Interface

The project includes a dedicated shopping cart sidebar containing:

- Cart header
- Close button
- Cart items container
- Empty-cart state
- JavaScript-based interaction

### Search Interface

Users can select a category before entering a search query.

Available categories include:

- All
- Groceries
- Mobiles
- Deals

### Promotional Content

The homepage contains:

- Promotional banner
- Hero section
- External Amazon.in reference
- Back-to-top navigation
