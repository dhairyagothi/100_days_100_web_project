## 📖 About The Project
This project is a detailed frontend replica of the Amazon web interface. It goes beyond static layouts by incorporating dynamic sliding sidebars and a responsive design that adapts to various screen sizes. 

## ✨ Key Features
* **Interactive Cart Sidebar:** Click the cart icon to open a sliding shopping cart drawer. 
* **Dynamic Hamburger Menu:** A functional "All" menu button that triggers a sliding category dropbox.
* **Responsive Layout:** Implements CSS media queries to ensure the UI adapts cleanly to mobile devices (screens under 768px and 480px).
* **Product Grids:** Flexbox-powered product category cards displaying items like Fashion, Daily Essentials, and Electronics.
* **Smooth Animations:** Includes CSS transitions for hover effects and sidebar sliding mechanics.

## 🛠️ Built With
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, flexbox layouts, and media queries.
* **Vanilla JavaScript:** DOM manipulation for toggling active classes on the sidebars.

## 📂 Project Structure
* `index.html`: The main structural layout of the clone.
* `style.css`: Contains all styling, responsive rules, and UI animations.
* `script.js`: Handles the click events for the sidebar drawer and cart toggles.
* `images/`: Directory containing all the optimized visual assets (hero images, product boxes, logos).
* `preview.png`: A screenshot of the finished UI layout.

## 🚀 How to Run Locally
1. Clone this repository to your local machine.
2. Navigate to the `New-AmazonClone` directory.
3. Open the `index.html` file in your preferred web browser. 
*(No external packages or local servers are required!)*
