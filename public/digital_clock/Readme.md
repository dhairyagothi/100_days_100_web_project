## 📖 Overview

Simple Digital Clock is a web-based clock application that displays the current time in real time. The project demonstrates fundamental web development concepts including DOM manipulation, JavaScript timing functions, and responsive design.

---

## ✨ Features

- 🕒 Real-time digital clock
- ⚡ Automatic time updates every second
- 🎨 Clean and modern user interface
- 📱 Responsive design
- 🔔 Alarm sound support
- 🚀 Lightweight and fast

## ⚙️ How It Works

1. JavaScript fetches the current system time.
2. The clock updates every second.
3. The UI automatically reflects the updated time.
4. Alarm functionality provides notification support.
