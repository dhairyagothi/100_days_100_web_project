# Digital Clock

## Description
A clean and accurate digital clock widget for the web. It provides real-time updates of the current time in a highly readable format, featuring a modern design that can be easily integrated into other projects.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Glassmorphism)
- JavaScript (Date Object & Time Intervals)

## Features
- **Real-time Clock**: Updates every second to show accurate current time.
- **Date Display**: Includes the current day, month, and year.
- **12/24 Hour Format**: Can be configured to show time in different formats.
- **Modern UI**: Features a sleek design with smooth typography and subtle shadows.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/digital_clock/`
3. Open `digitalclock.html` in your web browser.

## Folder Structure
```text
digital_clock/
 ├── digitalclock.html # Clock structure
 ├── digitalclock.js   # Real-time update logic
 └── digitalclock.css  # Layout and visual styling
```
