# Currency Exchange App

## Description
A dynamic currency exchange application that allows users to convert between various global currencies using real-time data. It features a clean, responsive interface and an intuitive selection process for currencies.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Custom Styling)
- JavaScript (Fetch API & Modular Logic)

## Features
- **Real-time Conversion**: Fetches the latest exchange rates from a public API.
- **Currency Data Selection**: Includes a comprehensive list of supported currencies.
- **Interactive UI**: User-friendly dropdowns for selecting "From" and "To" currencies.
- **Instant Results**: Displays converted amounts immediately upon input change or button click.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Exchange_Currency/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Exchange_Currency/
 ├── index.html       # Application structure
 ├── app.js           # Core conversion logic
 ├── data.js          # Currency metadata and helper data
 └── style.css        # Visual design and layout
```
