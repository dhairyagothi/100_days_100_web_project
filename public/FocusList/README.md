# FocusList

A lightweight task list app with progress tracking. Add tasks, mark them complete, and watch the progress bar update as you finish your list.

## Features

- Add tasks from a single input
- Toggle tasks as completed
- Delete tasks from the list
- Progress bar based on completed items

## How to Use

1. Type a task into the input field.
2. Click **Add** to create the item.
3. Click a task to mark it complete.
4. Remove items with the delete button.

## Files

- `index.html` - App UI and inline logic

## Notes

- The app uses only vanilla JavaScript.
- Progress is calculated directly from the current task list.
