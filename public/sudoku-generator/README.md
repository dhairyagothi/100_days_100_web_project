# 🧩 Sudoku Generator Web Application

A fully interactive **Sudoku Generator and Solver web application** built using HTML, CSS, and JavaScript.  
It generates random Sudoku puzzles, supports multiple difficulty levels, and allows users to solve puzzles directly in the browser with real-time validation and helpful features.

---

## 🚀 Features

### 🎯 Core Features
- 🧠 Dynamic Sudoku puzzle generation
- 🎚️ Difficulty levels: Easy, Medium, Hard
- 🎮 Interactive 9×9 Sudoku grid
- ⚡ Real-time input validation
- 🏁 Win detection system
- 🔄 New game & reset functionality

### 🧩 Advanced Features
- 💡 Hint system (auto-fills correct cell)
- ⏱️ Timer tracking
- 🧠 Auto-solve feature
- 🌙 Dark / Light mode toggle
- 💾 Local storage support (save progress)
- 📊 Game status updates

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Storage:** Browser Local Storage
- **No backend required**

---

## 🎮 How to Play

1. Select a difficulty level (Easy / Medium / Hard)
2. Click **New Game**
3. Fill the Sudoku grid with numbers 1–9
4. Use hints if needed
5. Click **Check** to validate your solution
6. Solve the puzzle to win 🎉
