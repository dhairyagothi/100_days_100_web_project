# DocNow - Healthcare Platform

## Description
DocNow is a modern web platform designed to bridge the gap between patients and healthcare providers. It allows users to search for doctors, explore various medical services, and book appointments online, all through a clean and user-friendly interface.

## Technologies Used
- HTML5
- CSS3 (Custom Properties & Flexbox)
- JavaScript (for navigation and dynamic elements)

## Features
- **Doctor Directory**: Browse through a list of qualified medical professionals across different specialties.
- **Appointment Booking**: A streamlined process for patients to request appointments online.
- **Service Overview**: Detailed information about the medical services and treatments offered.
- **Multi-page Navigation**: Includes About, Contact, Doctors, and Services pages for a complete experience.
- **Responsive Design**: Optimized for seamless use on both desktop and mobile devices.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/DocNow/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
DocNow/
 ├── images/          # Medical icons, doctor photos, and assets
 ├── pages/           # Sub-pages (About, Appointment, Contact, etc.)
 ├── index.html       # Landing page structure
 └── docstyle.css     # Unified styling for the platform
```
