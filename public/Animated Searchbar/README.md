# Animated Search Bar

## Description
A sleek, interactive search bar that expands and retracts with smooth animations. This project focuses on UI/UX micro-interactions, providing a modern feel to a common web element.

## Technologies Used
- HTML5
- CSS3 (Transitions & Flexbox)
- JavaScript (Vanilla)

## Features
- **Expandable Input**: The search bar expands when clicked or focused.
- **Smooth Animations**: High-quality CSS transitions for a premium feel.
- **Interactive Icon**: Clear visual feedback during state changes.
- **Minimalist Design**: Clean and modern aesthetic that fits into any project.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Animated Searchbar/`
3. Open `index.html` in your web browser.
