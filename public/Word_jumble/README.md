Word Jumble Game

Overview

Word Jumble is a fun and interactive word guessing game built using HTML, CSS, and JavaScript. Players are presented with scrambled words and must guess the correct word before the timer runs out. The game includes hints, scoring, lives, skips, and a modern glassmorphism-inspired user interface.

Features

- Scrambled word challenges
- Hint system for each word
- Countdown timer
- Score tracking
- Life system
- Skip functionality
- Restart game option
- Game Over modal with final score
- Dark/Light theme toggle
- Responsive design
- Modern glassmorphism UI effects

Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

How to Run Locally

1. Clone the repository:

git clone <repository-url>

2. Navigate to the project directory:

cd Word_jumble

3. Open "index.html" in your browser.

Or use a local server:

python -m http.server 8000

Then open:

http://localhost:8000

Gameplay

1. A scrambled word is displayed.
2. Read the provided hint.
3. Enter your guess in the input field.
4. Click Check Word.
5. Earn points for correct answers.
6. Use skips wisely.
7. Try to achieve the highest score before running out of lives.
