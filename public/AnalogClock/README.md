# Analog Clock

## Description
A dynamic, real-time analog clock built with HTML, CSS, and JavaScript. It features a polished visual interface with moving hands for hours, minutes, and seconds, synchronized with the system time.

## Technologies Used
- HTML5
- CSS3 (Transitions & Transforms)
- JavaScript (Vanilla)

## Features
- **Real-time Accuracy**: Automatically updates to match the system time.
- **Smooth Animation**: Continuous rotation of the clock hands using CSS transitions.
- **Sound Integration**: Includes a ticking sound for an authentic clock experience.
- **Responsive Layout**: Designed to look great on various screen sizes.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/AnalogClock/`
3. Open `index.html` in your web browser.
