# ⚡ Harry Potter Quiz

Harry Potter Quiz is an interactive web-based quiz application designed for fans of the Wizarding World. Test your knowledge of Harry Potter characters, spells, houses, magical creatures, and memorable events through a fun and engaging quiz experience.

---

## ✨ Features

- 🧙 Multiple-choice Harry Potter questions
- 📊 Real-time score tracking
- ⏱️ Instant answer feedback
- 🎯 Final score summary
- 🔄 Restart quiz functionality
- 📱 Fully responsive design
- 🎨 Clean and interactive user interface

---

## ▶️ Gameplay

1. Launch the application.
2. Read each Harry Potter question carefully.
3. Select the correct answer.
4. Continue until all questions are completed.
5. View your final score.
6. Restart the quiz to play again.

---

## 🎮 Quiz Controls

| Control | Description |
|---------|-------------|
| Start Quiz | Begins the quiz |
| Select Answer | Choose one of the available options |
| Next | Moves to the next question |
| Restart | Starts a new quiz session |
