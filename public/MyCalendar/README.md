# MyCalendar 🎉📅

An **Interactive Festival & Event Calendar** built with **HTML, CSS, and JavaScript**. It enables users to organize festivals, holidays, personal events, and daily notes with a modern, responsive interface and persistent storage using `localStorage`.

---

## ✨ Features

- 📅 Dynamic monthly calendar with Previous/Next month navigation.
- 🌙 Light & Dark mode with theme preference saved in `localStorage`.
- 📝 Add and save notes for each date.
- 🏷️ Categorize days as:
  - Normal Day
  - Festival / Holiday
  - Personal Event
- 💾 Notes and event categories persist after page refresh.
- 🎨 Month-specific accent colors for an engaging user experience.
- 🖼️ Dynamic month banner with seasonal images.
- 📍 Visual indicators for saved notes and tagged events.
- 📱 Fully responsive layout for desktop, tablet, and mobile devices.
- 🖥️ Optimized desktop layout where the calendar and notes panel fit within a single viewport without vertical scrolling.
- ⚡ Smooth animations, hover effects, and modern UI components.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/dhairyagothi/100_days_100_web_project.git
```

### 2. Navigate to the Project

```bash
cd 100_days_100_web_project/public/MyCalendar
```

### 3. Run the Project

Simply open **index.html** in your preferred web browser.

No additional dependencies or installation are required.

---

## 🎯 Usage

- Navigate between months using the **Previous** and **Next** buttons.
- Click on any date to select it.
- Choose an event category from the dropdown.
- Write notes for the selected day.
- Click **Save Note** to store your event.
- Toggle between **Light** and **Dark** mode using the theme switch.
- Your notes and preferred theme are automatically saved in your browser.
