# Emoji Mood Board

A simple and interactive mood tracker that lets you log how you're feeling throughout the day using emojis.

## Features
- 9 different mood options with emojis
- Logs mood with date and time
- Mood history saved in localStorage
- Clear all history option
- Smooth animations
- Fully responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript (localStorage)

## How to Run
1. Open `index.html` in any web browser
2. Click an emoji that matches your mood
3. Your mood gets logged with date and time
4. View your mood history below!
