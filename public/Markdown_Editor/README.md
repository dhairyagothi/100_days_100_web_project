# 📝 Markdown Editor

Markdown Editor is a responsive web application that enables users to write, edit, and preview Markdown content in real time. It provides a distraction-free writing environment with instant rendering, making it suitable for notes, blogs, documentation, and technical writing.

---

## ✨ Features

- 📝 Live Markdown editing
- 👀 Instant preview rendering
- 📋 Clean and minimal interface
- ⚡ Real-time updates
- 📱 Responsive layout
- 🎨 Modern user experience

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Markdown_Editor
```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Enter Markdown syntax in the editor.
3. View the rendered preview instantly.
4. Edit and format content in real time.
5. Use it for documentation, blogs, or notes.
