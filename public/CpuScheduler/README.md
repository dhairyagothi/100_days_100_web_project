# CPU Scheduling Simulator

An interactive web-based CPU scheduling algorithm simulator with dynamic Gantt charts, performance metrics, and real-time analysis.

## Features

- 11 scheduling algorithms: FCFS, SJF, SRTF, Round Robin, HRRN, LJF, LRTF, Priority, EDF, RMS, Multilevel Queue
- Interactive Gantt chart visualization with tooltips
- Performance metrics: turnaround time, waiting time, response time, CPU utilization, throughput
- Algorithm comparison and analysis with pros/cons
- Sample data loader for quick testing
- Responsive design

## Technologies Used

- HTML, CSS, JavaScript
- Tailwind CSS (via CDN)

## How to Run

1. Open `index.html` in a web browser
2. Select a scheduling algorithm
3. Set number of processes and input their details
4. Click "Run Simulation"
