# CPU Scheduling Simulator

## Description
An advanced interactive simulator designed to visualize and analyze various operating system CPU scheduling algorithms. This tool helps students and developers understand how different scheduling strategies impact system performance through dynamic Gantt charts and detailed performance metrics.

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript (Asynchronous Simulation & Canvas/DOM rendering)

## Features
- **Wide Range of Algorithms**: Supports FCFS, SJF, SRTF, Round Robin, HRRN, LJF, LRTF, Priority, EDF, RMS, and Multilevel Queue Scheduling.
- **Interactive Gantt Chart**: Dynamic visualization of process execution over time with tooltips for detailed information.
- **Performance Metrics**: Calculates and displays Average Waiting Time, Average Turnaround Time, Average Response Time, CPU Utilization, and Throughput.
- **Multilevel Queue Config**: Customize multiple queues with different scheduling strategies for complex simulations.
- **Real-time Analysis**: Provides a performance analysis summary based on the simulation results.
- **Responsive & Modern UI**: Built with Tailwind CSS for a premium, mobile-friendly experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/CpuScheduler/`
3. Open `index.html` in your web browser.
