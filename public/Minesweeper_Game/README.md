# 💣 Minesweeper Game

A fully responsive Minesweeper game built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- 💣 Random mine generation
- 🚩 Right click flagging system
- 🎮 Interactive gameplay
- 🏆 Win and lose detection
- 🔄 Restart button
- ⏱️ Live timer
- 📱 Responsive design
- 🎚️ Multiple difficulty levels
- ❓ Toggleable "How To Play" panel
- ✨ Clean modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## ▶️ How To Run

1. Clone repository

```bash
git clone https://github.com/dhairyagothi/100_days_100_web_project.git
```

2. Navigate to project

```bash
cd public/Minesweeper
```

3. Open `index.html` in browser

---

## 🎮 Gameplay Rules

- Left click to reveal cells
- Right click to place/remove flags
- Avoid mines
- Reveal all safe cells to win
