# Interactive Typing Speed Test

A clean, minimalist typing speed tester inspired by Monkeytype. Built with pure HTML, CSS, and Vanilla JavaScript, it offers a distraction-free environment to test and improve your typing speed.

## Features
- **Real-Time Highlighting:** Correct keystrokes glow, mistakes are flagged in red.
- **Live WPM Tracker:** See your Words Per Minute update in real-time.
- **Timer Options:** Choose between 15s, 30s, 60s, or 120s tests.
- **Comprehensive Results:** Displays final WPM, Accuracy, CPM (Characters Per Minute), and exact correct/incorrect character counts.
- **Theme Toggle:** Switch between Dark and Light mode.
- **Keyboard Shortcuts:** Press `Tab` + `Enter` to quickly restart the test.

## Technologies Used
- HTML5
- CSS3 (Variables, Flexbox, Keyframe Animations)
- Vanilla JavaScript (Event Listeners, DOM Manipulation, Timers, Math)

## How to run
Simply open `index.html` in any modern web browser.
