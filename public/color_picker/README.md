# 🎨 Color Picker

An interactive Color Picker web application built using HTML, CSS, and JavaScript. It allows users to explore colors using RGB sliders or HEX values, generate matching color palettes, convert between color formats, and save favorite colors for future use.

---

## ✨ Features

- 🎚 Interactive RGB sliders (Red, Green, Blue)
- 🎨 Live color preview
- 🔄 Two-way synchronization between RGB sliders and HEX input
- 📋 Copy color values instantly
  - Copy HEX
  - Copy RGB
  - Copy HSL
- 🌈 Automatic RGB → HSL conversion
- 🎨 Smart 5-color palette generation
  - Complementary colors
  - Analogous colors
  - Lighter shades
- 📌 Click any generated palette color to copy its HEX value
- ❤️ Save favorite colors
- 💾 Favorites stored using Local Storage
- ❌ Remove saved colors individually
- 🔔 Toast notifications for copy/save/remove actions
- 🏠 Back to Home navigation

## 📖 Usage

1. Move the RGB sliders to create a color.
2. Enter a HEX value to update the sliders automatically.
3. View the generated RGB, HEX, and HSL values.
4. Copy any color format using the copy buttons.
5. Explore the automatically generated color palette.
6. Click a palette color to copy its HEX value.
7. Save colors to your Favorites list.
8. Remove saved colors whenever needed.
