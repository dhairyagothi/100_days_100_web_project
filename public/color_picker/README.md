# Color Picker Tool

## Description
A simple and efficient color picker tool for web developers and designers. It allows users to select colors using a visual interface and provides the corresponding HEX or RGB values for use in their projects.

## Technologies Used
- HTML5 (Input type color)
- CSS3 (Flexbox)
- JavaScript (DOM Manipulation)

## Features
- **Visual Color Selection**: Uses the native browser color picker for a familiar experience.
- **Real-time Preview**: Shows the selected color in a large preview box instantly.
- **Value Display**: Displays the HEX code and RGB values of the chosen color.
- **Copy to Clipboard**: (If implemented) Easy way to copy color codes for use in code.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/color_picker/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
color_picker/
 ├── index.html       # Tool structure
 ├── script.js        # Color update logic
 └── style.css        # Simple and clean UI styling
```
