# 📖 Word Dictionary

A responsive web-based dictionary application that allows users to search for English words and instantly view their meanings, phonetics, pronunciation, synonyms, and example sentences using the Free Dictionary API.

## ✨ Features

- Search any English word
- Word definitions
- Phonetic spelling
- Audio pronunciation
- Synonyms (when available)
- Example sentences
- Responsive UI
- Error handling for invalid words

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API

## 🌐 API Used

Free Dictionary API

https://api.dictionaryapi.dev/

No API key is required.

## 🚀 Getting Started

1. Clone the repository.

2. Navigate to:

```
public/Word_Dictionary
```

3. Open:

```
index.html
```

in your browser.
