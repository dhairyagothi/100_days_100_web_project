# Shadow Vault Escape

Shadow Vault Escape is a dark, terminal-driven escape game where you solve room puzzles, manage a countdown timer, and unlock deeper vault sectors with commands and hints.

## Features

- Multi-level room progression
- Command-driven puzzle solving
- Hint, inventory, and status actions
- Countdown timer with failure state
- Modal-based start and completion flow

## How to Play

1. Enter your operative profile.
2. Start the mission and read the room clues.
3. Use commands like `hint`, `inventory`, and `status`.
4. Solve each room to descend deeper into the vault.
5. Escape before the timer expires.

## Files

- `index.html` - Game UI and modal layout
- `style.css` - Visual styling
- `script.js` - Puzzle logic, timer, and room progression

## Notes

- The game is designed as a suspenseful single-page browser experience.
- Higher levels generate puzzles dynamically as you progress.
