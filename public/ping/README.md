# Ping Pong Game

## Description
A classic browser-based Ping Pong game for two players or player vs computer. This project implements smooth paddle movement and ball physics using the HTML5 Canvas API, providing a nostalgic arcade experience.

## Technologies Used
- HTML5 (Canvas API)
- CSS3
- JavaScript (Game Physics & Collision Detection)

## Features
- **Smooth Controls**: Responsive paddle movement via keyboard or mouse.
- **Ball Physics**: Realistic bouncing and speed increments as the game progresses.
- **Score Tracking**: Displays scores for both players in real-time.
- **Simple & Clean UI**: Focused on gameplay with a minimalist design.
- **Restart Mechanism**: Easy to start a new match after a win.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/ping/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
ping/
 ├── index.html       # Game container
 ├── script.js        # Core physics and game loop
 └── style.css        # Basic layout and canvas styling
```
