# Recipe Finder

## Description
A simple and effective web application for finding and exploring delicious recipes. This project allows users to browse through a curated collection of culinary ideas, providing essential information like ingredients and instructions for each dish.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (for data retrieval and rendering)
- JSON (for recipe data storage)

## Features
- **Search & Filter**: Quickly find recipes based on keywords or categories.
- **Detailed Recipe Views**: Includes ingredients lists, cooking times, and step-by-step instructions.
- **Dynamic Content**: Loads recipe data from a central JSON file for easy maintenance.
- **Visual Presentation**: Features high-quality images to make each dish enticing.
- **Clean Interface**: A focused design that makes finding your next meal easy and enjoyable.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/recipe/`
3. Open `main.html` in your web browser.

## Folder Structure
```text
recipe/
 ├── image.jpg        # High-quality dish visuals
 ├── main.html        # Main interface structure
 ├── rec.html         # Individual recipe view template
 ├── style.css        # Layout and visual design
 └── text.json        # Centralized recipe data
```
