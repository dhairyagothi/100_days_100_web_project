# 🍳 Recipe

Recipe is a responsive web application that allows users to explore delicious recipes with an elegant and user-friendly interface. It helps users discover dishes, view ingredients, and follow step-by-step cooking instructions.

---

## ✨ Features

- 🍽️ Browse delicious recipes
- 🔍 Search recipes by name
- 🥗 View ingredients and cooking instructions
- 📱 Fully responsive design
- 🎨 Modern and clean user interface
- ⚡ Smooth user experience

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd recipe
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Browse available recipes.
3. Search for your favorite dish.
4. View ingredients and preparation steps.
5. Follow the recipe and enjoy cooking.
