# Image Search Engine

## Description
A powerful and intuitive image search engine that allows users to discover high-quality images from the web. It integrates with the Unsplash API to provide a vast library of photos with real-time search capabilities.

## Technologies Used
- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (Fetch API & Async/Await)
- Unsplash API

## Features
- **Real-time Search**: Fetches high-resolution images based on user queries.
- **Infinite Scroll/Show More**: Load more results seamlessly without refreshing the page.
- **Responsive Gallery**: Displays images in a beautiful, adaptive grid layout.
- **Direct Links**: Each image includes a link to its original source on Unsplash.
- **Clean Interface**: Focused on providing a distraction-free search experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Image Search Engine/`
3. Get a free API key from [Unsplash Developers](https://unsplash.com/developers).
4. Update the `accessKey` constant at the top of `script.js` with your own key.
5. Open `index.html` in your web browser.

## Folder Structure
```text
Image Search Engine/
 ├── index.html       # Search interface structure
 ├── script.js        # API integration and result rendering
 └── style.css        # Gallery and layout styling
```
