# FocusForge

A polished Pomodoro-style focus timer built for productivity. FocusForge combines timed work sessions, short breaks, theme switching, session tracking, and motivational quotes in one interface.

## Features

- Focus and short-break modes
- Adjustable session durations
- Auto-switching between modes
- Session count tracking
- Light and dark themes
- Optional browser notifications and sound cues
- Editable timer display with quick adjustments

## How to Use

1. Open the app.
2. Choose your timer settings.
3. Start a focus session.
4. Let the timer guide work and break cycles.

## Files

- `index.html` - App shell and UI layout
- `style.css` - Visual styling
- `script.js` - Timer logic, settings, storage, and UI updates

## Notes

- The app stores preferences locally in the browser.
- Audio cues are generated with the Web Audio API.
