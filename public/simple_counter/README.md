# Simple Counter

A minimalist, premium-designed counter application built with vanilla HTML, CSS, and JavaScript.

## Features
- Increase/Decrease functionality
- Reset to zero
- Dynamic color coding for positive/negative values
- Smooth scaling animations on update
- Modern dark-mode aesthetic

## Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Variables)
- JavaScript (ES6+)

## How to Run
1. Open `index.html` in any modern web browser.
2. Use the buttons to interact with the counter.
