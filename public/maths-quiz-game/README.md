# ➗ Math Quiz Game

Math Quiz Game is an interactive browser-based educational game that helps users improve their mathematical skills by solving randomly generated arithmetic questions. It provides a fun and engaging way to practice calculations while tracking performance.

---

## ✨ Features

- ➕ Random math questions
- ⏱️ Timed quiz gameplay
- 🎯 Instant answer validation
- 🏆 Score tracking
- 🔄 Restart quiz option
- 📱 Fully responsive design
- 🎨 Clean and interactive interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd math-quiz-game
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Gameplay

1. Launch the game.
2. Read the displayed math question.
3. Enter the correct answer.
4. Receive instant feedback.
5. Complete all questions and view your final score.
