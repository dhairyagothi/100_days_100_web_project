# Quotely-Laughs - Random Joke Generator

## Description
A lighthearted web application that serves up random jokes and funny quotes to brighten your day. It uses an external API to fetch a continuous stream of humor, ensuring that you always have a fresh laugh at your fingertips.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (Fetch API & Joke API)

## Features
- **Instant Humor**: Generates a new joke or funny quote with a single click.
- **Diverse Categories**: Includes various types of humor, from puns to witty one-liners.
- **One-Click Sharing**: (If implemented) Easily share your favorite jokes on social media.
- **Clean & Joyful UI**: Features a bright and engaging design that complements the humorous content.
- **Fast Performance**: Fetches and displays jokes rapidly for a seamless experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Quotely-Laughs/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Quotely-Laughs/
 ├── index.html       # Application structure and embedded styles
 └── script.js        # API integration and joke rendering logic
```
