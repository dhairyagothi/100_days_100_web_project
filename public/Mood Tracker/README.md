# Mood Flow (Mood Tracker)

## Description
Mood Flow is a comprehensive wellness application designed to help users track and visualize their emotional health over time. By recording daily moods, intensity levels, and reflective notes, users can gain insights into their emotional patterns and receive personalized well-being recommendations.

## Technologies Used
- HTML5
- CSS3 (Materialize CSS Framework)
- JavaScript (Vanilla)
- Chart.js (for data visualization)
- Font Awesome (for iconography)

## Features
- **Daily Mood Logging**: Easily select your mood using interactive emoji buttons.
- **Intensity Meter**: Use a range slider to specify the strength of your emotions.
- **Journaling**: Add detailed notes to provide context to your mood entries.
- **Mood History Graph**: Visualize your emotional trends over time with dynamic line charts.
- **Persistent Storage**: Uses LocalStorage to keep your entries saved across browser sessions.
- **Personalized Recommendations**: Receive tailored advice and activities based on your current mood.
- **Dark/Light Mode**: Toggle between themes for comfortable viewing in any lighting.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Mood Tracker/`
3. Open `index.html` in your web browser.
