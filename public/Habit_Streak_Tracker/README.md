# 🔥 Habit Streak Tracker

A clean, dark-themed habit tracking web app that helps you build daily habits and maintain streaks.

## Features
- Add custom daily habits
- Mark habits as done each day
- Streak counter (resets if you miss a day)
- Data persists with localStorage
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- localStorage API

## How to Run
1. Open `index.html` in any modern browser
2. Add your habits using the input field
3. Click "Mark Done" each day to maintain your streak
