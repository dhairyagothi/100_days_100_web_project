# Love Calculator

## Description
A lighthearted web application that calculates the "love percentage" between two names. It features a playful, heart-themed design with interactive animations to make the experience fun for users.

## Technologies Used
- HTML5
- CSS3 (3D Transforms & Animations)
- JavaScript (Random Logic & DOM Manipulation)

## Features
- **Name Input**: Fields for entering two names to compare.
- **Percentage Calculation**: A pseudo-random algorithm that "calculates" the love score.
- **3D Visuals**: Incorporates 3D heart icons and vibrant pink/white themes.
- **Micro-animations**: Smooth transitions and heart-beat effects.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Love-Calculator/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Love-Calculator/

 ├── script.js        # Calculator logic
 └── style.css        # Heart-themed styling
```
