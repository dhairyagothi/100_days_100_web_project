# SpendWise

SpendWise is a premium-style expense tracker that helps you set income, record expenses, filter transactions, and visualize your budget with a category breakdown chart.

## Features

- Set or update monthly income
- Add expenses with categories
- Filter the expense history by category
- View income, expense, and balance cards
- See a category breakdown chart
- Persist data in local storage

## How to Use

1. Enter your monthly income.
2. Add expenses as you spend.
3. Use the category filter to review history.
4. Watch the dashboard update automatically.

## Files

- `index.html` - Dashboard layout and forms
- `style.css` - Visual styling
- `script.js` - Expense tracking and local storage logic

## Notes

- The app stores data in the browser with local storage.
- Category breakdown and totals update dynamically from the entered data.
