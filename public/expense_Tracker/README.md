# Expense Tracker

## Description
A practical personal finance application to help users manage their income and track various categories of spending. It provides a real-time budget overview, including total income, total spent, and the remaining balance.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Layout)
- JavaScript (DOM Manipulation & State Tracking)

## Features
- **Income Management**: Add and track total income.
- **Categorized Spending**: Includes categories like Travel, Food, Transport, Utilities, EMI, and more.
- **Budget Overview**: Real-time updates for Total Money, Money Spent, and Money Left.
- **Dynamic Content**: Seamlessly switches between Income and Spending views without page refreshes.
- **Currency Formatting**: Automatically formats amounts in Indian Rupees (₹).

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/expense_Tracker/`
3. Open `index.html` in your web browser.
