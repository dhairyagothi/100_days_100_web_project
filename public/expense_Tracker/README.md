# 💰 Expense Tracker

A modern and responsive Expense Tracker web application that helps users efficiently manage their income and expenses with an interactive dashboard, spending insights, and transaction history.

---

## 📖 Project Overview

Expense Tracker is a browser-based finance management application built using HTML, CSS, and JavaScript. It allows users to record income and expense transactions while providing visual summaries of their financial activities.

The application offers real-time calculations, category-wise analysis, dark mode support, and local data management for an enhanced user experience.

---

## ✨ Features

### 💵 Transaction Management

- Add income entries
- Add expense entries
- Enter amount, date, category, and description
- Edit/Delete transactions (if supported)
- View complete transaction history

### 📊 Dashboard

- Current Balance
- Total Income
- Total Expenses
- Average Transaction
- Savings Rate

### 📈 Expense Analytics

- Category-wise expense breakdown
- Progress bars for each category
- Top spending category indicator
- Circular percentage visualization

### 🌙 User Interface

- Dark Mode
- Responsive Design
- Dashboard View
- Transactions View
- History Log

### 🗂 Data Management

- Backup data
- Clear all data
- Local browser storage

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/dhairyagothi/100_days_100_web_project.git
```

2. Navigate to the project folder

```bash
cd 100_days_100_web_project/public/Expense_Tracker
```

3. Open

```
index.html
```

in your browser.
