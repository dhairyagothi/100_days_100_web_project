# ☕ CAFFLIX — Modern Web Concept

CAFFLIX is a UI/UX web concept inspired by the Bento Grid layout. This project focuses on clean structure, modern visuals, and responsive design using only HTML & CSS.

## ✨ Features
* **Bento Grid Layout** using CSS Grid
* **Fully Responsive** (desktop → mobile)
* **Smooth Hover Effects** for better interaction
* **Sticky Navigation Bar** with a clear CTA

## 🛠️ Tech Stack
* HTML5
* CSS3 (Grid, Flexbox, Media Queries)
* Google Fonts (Montserrat)

## 🎨 Color Palette
* **Primary:** `#3E5C76`
* **Secondary:** `#FFD3C4`
* **Accent:** `#E88D83`
