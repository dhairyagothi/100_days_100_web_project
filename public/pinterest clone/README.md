# Pinspire (Pinterest Clone)

A responsive Pinterest-style moodboard UI with a masonry grid, infinite scroll, and an interactive pin modal.

## Features
- Masonry-style pin grid with lazy-loaded images
- Infinite scroll via `IntersectionObserver`
- Search filter and saved-only toggle
- Light/dark theme toggle with persistence
- Pin modal with save/share actions

## Run Locally
Open `index.html` in your browser.

## Project Files
- `index.html`: Layout and UI structure
- `style.css`: Theme tokens, layout, and animations
- `script.js`: Pin generation, filtering, modal, and theme logic
- `logo_p.jpg`: App icon/logo

## Notes
- Image content is sourced from Unsplash URLs.
- Saved pins and theme preference are stored in `localStorage`.
