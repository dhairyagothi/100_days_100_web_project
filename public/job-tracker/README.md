# 💼 Job Tracker

Job Tracker is a web application that helps users organize and monitor their job applications efficiently. It enables users to record application details, update application status, and manage their job search from a single dashboard.

---

## ✨ Features

- 💼 Add new job applications
- 📋 View all applications
- ✏️ Edit application details
- 🗑️ Delete applications
- 📊 Track application progress
- 📱 Responsive design
- 🎨 Clean and intuitive user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd job-tracker
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Add a new job application.
3. Enter company, position, and other relevant details.
4. Update the application status as you progress.
5. Manage and review your job search efficiently.
