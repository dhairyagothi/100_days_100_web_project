# System Design Visualizer

An interactive frontend-based architecture diagram builder built using HTML, CSS, and JavaScript.

## Features

- Create draggable architecture nodes
- Simulate scalable system components
- Responsive dark-themed UI
- Interactive drag-and-drop experience
- Clear board functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Components Available

- API Server
- Database
- Cache Layer

## Future Improvements

- SVG connection lines
- Export diagrams as PNG
- Zoom and pan support
- Prebuilt architecture templates
- Save/load diagrams

## How to Run

1. Open `index.html`
2. Start adding nodes
3. Drag components freely
