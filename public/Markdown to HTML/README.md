# 📝 Markdown to HTML

Markdown to HTML is a lightweight web application that converts Markdown syntax into HTML in real time. It provides an easy way for developers, technical writers, and content creators to preview formatted HTML while writing Markdown.

---

## ✨ Features

- 📝 Write Markdown content
- 🔄 Real-time HTML conversion
- 👀 Live preview
- ⚡ Instant rendering
- 📱 Fully responsive design
- 🎨 Clean and minimal interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd "Markdown to HTML"
```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Write Markdown in the editor.
3. View the generated HTML instantly.
4. Edit content and preview changes in real time.
5. Use it for documentation, blogs, or learning Markdown.
