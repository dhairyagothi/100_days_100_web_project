# 📖 Overview

Pokedex is a JavaScript-based web application that integrates with the PokeAPI to provide real-time Pokémon information. Users can search Pokémon by their name or Pokédex number and instantly view details.

The project focuses on API integration, asynchronous JavaScript, responsive UI design, and interactive user experience.

---

# ✨ Features

- Search Pokémon by name
- Search Pokémon by ID
- Real-time API integration
- Pokémon image display
- Type information
- Height and weight details
- Responsive design
- Error handling
- Loading states
- Clean UI

# 🔍 Search Flow

1. User enters Pokémon name.
2. JavaScript sends API request.
3. PokeAPI returns data.
4. DOM updates dynamically.
5. Pokémon details appear.

---

# 🌐 API Endpoint

```text
https://pokeapi.co/api/v2/pokemon/{name}
```

Example:

```text
https://pokeapi.co/api/v2/pokemon/pikachu
```
