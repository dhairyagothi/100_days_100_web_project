Dots and Boxes Game

A modern and Interactive 2 player DOts and Boxes game  built using HTML, CSS nd JavaScript.

Features:

- Two-player gameplay
- Custom player names
- Dynamic glowing turn indicators
- Score tracking
- Winner modal popup
- Responsive modern UI
- Smooth gameplay interactions

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Play
1. Players take turns drawing lines.
2. Completing a box gives the player a point.
3. A player who completes a box gets another turn.
4. Player with the highest score wins.
