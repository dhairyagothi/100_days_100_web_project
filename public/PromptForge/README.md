# 🚀 PromptForge

**PromptForge** is an AI Prompt Optimization & Token Intelligence Dashboard built using **HTML, Tailwind CSS, Vanilla JavaScript, and GSAP**.

It helps users transform simple prompts into structured AI-ready prompts while providing real-time token estimation, API cost analysis, and reusable prompt templates.

---

## ✨ Features

### 🧠 AI Prompt Refiner

Convert basic prompts into structured prompts using prompt engineering concepts inspired by:

- CO-STAR Framework
- RTCE Framework
- Role-Based Prompting

#### Example

**Input**

```text
Write a blog about Artificial Intelligence
```

**Output**

```text
# CONTEXT
The user needs assistance with the following task:

Write a blog about Artificial Intelligence

# OBJECTIVE
Provide a detailed, accurate, and useful response.

# STYLE
Professional and structured.

# TONE
Clear and concise.
```

---

### 📊 Live Token Intelligence Matrix

Real-time analysis of:

- Character Count
- Word Count
- Estimated Token Count
- Prompt Metrics

Updates instantly as users type.

---

### 💰 API Cost Calculator

Estimate AI API costs across multiple models:

- GPT-4o
- Claude 3.5 Sonnet
- Gemini Pro

Cost calculations update dynamically based on estimated token usage.

---

### 📚 Template Library

Quick-access templates for:

- Debugging
- Summarization
- Creative Writing
- Interview Preparation
- Concept Explanation

One click injects the selected template into the prompt editor.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/dhairyagothi/100_days_100_web_project.git
```

### Navigate to Project Directory

```bash
cd public/PromptForge
```

### Run Locally

Open:

```text
index.html
```

Or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
