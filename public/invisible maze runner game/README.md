# 👻 Invisible Maze Runner Game

Invisible Maze Runner Game is a browser-based puzzle game where players must navigate through an invisible maze using memory, logic, and exploration. The challenge lies in finding the correct path without being able to see the maze layout, making each playthrough both exciting and mentally engaging.

---

## ✨ Features

- 👻 Invisible maze gameplay
- 🧩 Challenging puzzle mechanics
- 🎮 Simple keyboard controls
- 🔄 Restart and replay functionality
- 📱 Fully responsive design
- 🎨 Minimal and engaging interface

## ▶️ Gameplay

1. Launch the game.
2. Use the keyboard controls to move your character.
3. Carefully explore the invisible maze.
4. Avoid dead ends and remember successful paths.
5. Reach the destination to complete the level.
