# Neon Runner 2.0

A pure HTML5, CSS3, and JavaScript procedural maze game.

## Features
- **Procedural Generation**: Every maze is unique, generated using a recursive backtracking algorithm.
- **Scaling Difficulty**: Choose between Easy, Medium, and Hard. Higher difficulty increases the grid complexity.
- **Victory States**: High scores (minimum steps) are saved to your browser's local storage for each difficulty.
- **Fluid Controls**: Support for WASD and Arrow Keys.
- **Neon Aesthetic**: A polished, dark-tech interface with smooth animations and modal feedback.

## Controls
- **Move**: `W`, `A`, `S`, `D` or `Arrow Keys`
- **Restart**: Change difficulty or click "New Run" after winning.

## Files
1. `index.html` - Game structure and UI.
2. `style.css` - Neon styling and layout.
3. `script.js` - Maze generation and game logic.
