# Canvas Maze Game

## Description
An engaging, browser-based maze game where players navigate through randomly generated paths to reach the goal. Built with HTML5 Canvas, this project demonstrates algorithmic path generation and interactive user controls.

## Technologies Used
- HTML5 (Canvas)
- CSS3
- JavaScript
- jQuery
- jQuery TouchSwipe (for mobile support)

## Features
- **Dynamic Maze Generation**: Each game creates a unique maze layout.
- **Difficulty Levels**: Choose from Easy, Medium, Hard, and Extreme to test your skills.
- **Responsive Controls**: Supports both keyboard arrow keys and touch gestures for mobile play.
- **Victory Feedback**: Displays a congratulatory message and move count upon completion.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Maze-Game-main/`
3. Open `index.html` in your web browser.
