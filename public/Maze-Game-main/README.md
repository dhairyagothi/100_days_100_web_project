# 🧩 Maze Game

Maze Game is an interactive browser-based puzzle game where players navigate through a maze to reach the destination while avoiding obstacles and dead ends. The project demonstrates game logic, keyboard controls, and responsive web design using modern web technologies.

---

## ✨ Features

- 🧩 Interactive maze gameplay
- 🎮 Keyboard-based controls
- 🎯 Reach the goal to complete the maze
- 🔄 Restart game functionality
- 📱 Fully responsive design
- 🎨 Smooth animations and modern interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Maze-Game-main
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Gameplay

1. Launch the game.
2. Use the keyboard controls to move through the maze.
3. Avoid wrong paths and obstacles.
4. Reach the destination to win the game.
5. Restart and try different strategies.
