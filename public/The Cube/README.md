# The Cube

## Description
A responsive web project named The Cube. This project demonstrates modern web development techniques and interactive user interface design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- **Responsive Layout**: Adapts to different screen sizes.
- **Interactive UI**: Provides a seamless user experience.
- **Clean Code**: Well-structured and maintainable codebase.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/The Cube/`
3. Open `index.html` in your web browser.

