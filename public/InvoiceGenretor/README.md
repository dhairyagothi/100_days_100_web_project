# 🧾 Invoice Generator

Invoice Generator is a web-based application that enables users to create professional invoices quickly and efficiently. Users can enter customer information, add products or services, calculate totals automatically, and generate a printable invoice through an intuitive interface.

---

## ✨ Features

- 🧾 Generate professional invoices
- 👤 Add customer details
- 📦 Add multiple products or services
- 🧮 Automatic subtotal and total calculations
- 🖨️ Print-ready invoice layout
- 📱 Fully responsive design
- 🎨 Clean and user-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd InvoiceGenerator
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Enter customer information.
3. Add products or services with quantity and price.
4. Review the automatically calculated totals.
5. Generate and print the invoice.
