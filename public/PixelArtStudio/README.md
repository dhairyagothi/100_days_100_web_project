# Pixel Art Studio

An advanced browser-based pixel art editor built with vanilla HTML, CSS, and JavaScript.

## Features

- **Configurable Canvas:** Adjustable grid sizes (8x8 up to 128x128).
- **Tool Suite:** Pencil, Eraser, Flood Fill, Eyedropper.
- **Animation Timeline:** Multi-frame support, onion skinning, and playback.
- **Undo/Redo:** Full history stack.
- **Export:** Save artwork as PNG.
- **Collaboration:** Real-time sync across multiple tabs using `BroadcastChannel`.

## Tech Stack

- Vanilla HTML5 / CSS3 / JavaScript
- HTML5 Canvas API
- CSS Custom Properties & Grid Layout

## How to Run

Just open `index.html` in any modern web browser. No build steps required.
