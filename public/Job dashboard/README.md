# 💼 Job Dashboard

<p align="center">
  A modern and responsive Job Dashboard built using HTML, CSS, and JavaScript that allows users to browse, search, filter, and save job opportunities through a clean and intuitive interface.
</p>

---

## 📖 Overview

Job Dashboard is a frontend web application designed to simplify the job searching experience. It enables users to browse available jobs, apply multiple filters, view detailed job descriptions, and save interesting opportunities for later.

The project focuses on providing a responsive and user-friendly interface while demonstrating core frontend development concepts such as DOM manipulation, dynamic filtering, reusable UI components, and local data management.

---

# ✨ Features

### 🔍 Smart Job Filtering

- Search jobs by title
- Search jobs by location
- Filter by posting date
- Filter by salary range
- Filter by employment type
- Filter by work shift
- Filter by education level
- Sort jobs using multiple criteria

---

- View multiple job cards
- Company information

- Work shift
