# Job Dashboard

## Description
A comprehensive job search dashboard that allows users to browse job listings, view detailed company information, and filter jobs by category. It features a clean, professional UI for job seekers.

## Technologies Used
- HTML5
- CSS3 (Custom Properties & Grid)
- JavaScript (DOM Manipulation & Filtering)

## Features
- **Job Listings**: Display various job opportunities with details like title, company, and location.
- **Company Pages**: Dedicated sub-pages for specific companies (e.g., ITWorlds, ITinfosy).
- **Interactive Search**: Search for jobs based on titles or keywords.
- **Responsive Layout**: Designed to work across different screen sizes.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Job dashboard/`
3. Open `jobs.html` in your web browser.

## Folder Structure
```text
Job dashboard/
 ├── image/           # Assets and company logos
 ├── jobs.html        # Main dashboard page
 ├── jobs.css         # Styling for the dashboard
 ├── jobs.js          # Interactive features
 └── *.html           # Individual company detail pages
```
