# 🎵 Music Website

Music Website is a modern and responsive web application that showcases music albums, artists, playlists, and featured tracks through an attractive user interface. The project demonstrates front-end web development concepts while delivering an engaging music-themed browsing experience.

---

## ✨ Features

- 🎵 Beautiful landing page
- 🎧 Featured music section
- 🎤 Artist showcase
- 📀 Albums and playlists
- 📱 Fully responsive design
- 🎨 Modern UI/UX

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd music_website
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code
