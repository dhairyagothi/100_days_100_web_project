# Sefr Coffee

A simple front-end coffee menu project built with:

- HTML
- CSS
- Tailwind CSS
- JavaScript

## Description
This project is a minimal coffee product showcase.  
It includes:

- A splash/start screen
- Category filters (e.g. all, ice-coffee, hot-coffee, americano, espresso)
- Product cards with image, name, and price
- Simple pagination
