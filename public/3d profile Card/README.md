# 3D Profile Card

## Description
An elegant 3D profile card component featuring smooth hover animations and perspective effects. The card displays a user profile with an avatar image, social links, and a modern glassmorphism-inspired design.

## Technologies Used
- HTML5
- CSS3 (3D Transforms, Perspective, Transitions)

## Features
- **3D Hover Effect**: Card tilts and rotates on hover using CSS perspective.
- **Profile Layout**: Clean display of avatar, name, and social information.
- **Smooth Animations**: Polished CSS transitions for all interactive states.
- **Modern Design**: Glassmorphism-inspired styling with shadows and gradients.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/3d profile Card/`
3. Open `index.html` in your web browser.
