# Plant Shop Landing Page

## Description
A beautiful and serene landing page for an online plant shop. This project focuses on high-quality visual presentation and a clean user interface to showcase various indoor and outdoor plants, perfect for botanical enthusiasts.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (for interactions and smooth scrolling)

## Features
- **Visual Product Showcase**: High-quality image gallery for different plant species.
- **Modern Aesthetic**: Features a clean, nature-inspired color palette and typography.
- **Responsive Layout**: Optimized for a great viewing experience on all screen sizes.
- **Interactive Elements**: Includes hover effects and simple navigation transitions.
- **Call-to-Action**: Strategically placed buttons for exploring collections and making purchases.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Plant/`
3. Open `main.html` in your web browser.

## Folder Structure
```text
Plant/
 ├── images/          # Plant photos and brand assets
 ├── main.html        # Landing page structure
 ├── script.js        # UI interaction logic
 └── style.css        # Layout and visual design
```
