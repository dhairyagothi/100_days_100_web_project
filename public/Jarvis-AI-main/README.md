# JARVIS - Virtual Assistant

## Description
A voice-activated virtual assistant inspired by JARVIS from Iron Man. This project uses the Web Speech API to recognize voice commands and respond with information or perform simple actions like opening websites.

## Technologies Used
- HTML5
- CSS3 (Glassmorphism & Flexbox)
- JavaScript (Web Speech API)

## Features
- **Voice Recognition**: Listen to user commands using the microphone.
- **Voice Synthesis**: Responds to the user using text-to-speech.
- **Common Commands**: Can answer "Who are you?", "How are you?", open Google, Facebook, Instagram, and more.
- **Animated Interface**: Features a futuristic UI with an animated core gif.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Jarvis-AI-main/`
3. Open `index.html` in your web browser.
4. **Note**: Requires microphone permissions to function.
