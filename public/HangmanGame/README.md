# Hangman Game

## Description
A classic word-guessing game where players try to uncover a hidden word by guessing letters one by one. Each incorrect guess brings the "hangman" closer to completion. This project features a clean UI and a large dictionary of words for endless fun.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (String Manipulation & Game Logic)

## Features
- **Virtual Keyboard**: On-screen keyboard for easy letter selection.
- **Dynamic Hangman Illustration**: Visual representation of the hangman that updates with each wrong guess.
- **Random Word Generation**: Fetches or picks a new word for every game session.
- **Win/Loss Detection**: Instant feedback when the word is guessed or when the player runs out of tries.
- **Hint System**: (If implemented) Provides categories or starting letters to help the player.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/HangmanGame/`
3. Open `index.html` in your web browser.
