# 🎯 Hangman Game

Hangman Game is a browser-based word guessing game where players attempt to discover a hidden word by guessing one letter at a time. Each incorrect guess brings the player closer to losing, making the game both fun and challenging.

---

## ✨ Features

- 🎮 Classic Hangman gameplay
- 🔤 Random word selection
- ⌨️ Keyboard-based letter input
- ❤️ Limited incorrect guesses
- 📊 Win/Loss detection
- 🔄 Restart game option
- 📱 Responsive design
- 🎨 Simple and interactive user interface

## ▶️ Gameplay

1. Launch the game.
2. A hidden word is randomly selected.
3. Guess one letter at a time.
4. Correct guesses reveal letters in the word.
5. Incorrect guesses reduce the remaining attempts.
6. Guess the complete word before running out of attempts to win.
