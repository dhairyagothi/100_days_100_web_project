# Marketing Website (SEO Agency)

## Description
A professional, responsive marketing agency website template designed to showcase SEO, content marketing, and web development services. It features a clean layout with a hero section, service highlights, and a comprehensive footer.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 4 (CDN)
- Google Fonts

## Features
- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop.
- **Sticky Navigation**: Easy access to site sections via a sticky top navbar.
- **Hero Section**: Engaging banner with a call-to-action to grab user attention.
- **Service Cards**: Cleanly presented services with images and descriptions.
- **Bootstrap Integration**: Utilizes Bootstrap's grid system and components for a modern look.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/marketing_website/`
3. Open `index.html` in your preferred web browser.
