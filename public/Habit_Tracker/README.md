# Habit Tracker

## Description
A personal productivity tool designed to help users build and maintain positive habits. It allows users to list their daily habits, track completion, and visualize their progress over time, fostering consistency and accountability.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (DOM Manipulation & Local Storage)

## Features
- **Habit Logging**: Add new habits with custom names and frequencies.
- **Progress Tracking**: Toggle completion for each habit on a daily basis.
- **Persistence**: Saves habit data to the browser's local storage so progress is never lost.
- **Clean Dashboard**: A minimalist and distraction-free interface focused on goal achievement.
- **Dynamic Updates**: Real-time visualization of streaks and completion rates.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Habit_Tracker/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Habit_Tracker/

 ├── script.js        # Habit management and storage logic

```
