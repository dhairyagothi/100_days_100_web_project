# Notes App

## Description
A functional and intuitive note-taking application that allows users to quickly jot down ideas, tasks, or reminders. It features a clean interface with persistent storage capabilities (if implemented via localStorage).

## Technologies Used
- HTML5
- CSS3 (Flexbox & Box Shadows)
- JavaScript (DOM Manipulation & Local Storage)

## Features
- **Add/Edit/Delete**: Create new notes, edit existing ones, or remove them easily.
- **Dynamic Grid**: Notes are displayed in an organized grid layout.
- **Search Functionality**: Quickly find specific notes using a search bar.
- **Persistent Storage**: Saves notes to the browser's local storage so they remain after refresh.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/notes-app/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
notes-app/
 ├── index.html       # Main application structure
 ├── script.js        # Note management logic
 └── style.css        # Clean UI styling
```
