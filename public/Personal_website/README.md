# Personal Website

## Description
A clean and professional personal website template designed to showcase an individual's background, skills, and portfolio. It features a modern layout with dedicated sections for an "About Me" introduction, project showcases, and professional experience.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)

## Features
- **Hero Section**: Welcoming landing area with a personal introduction.
- **Project Showcase**: Grid-based layout for displaying recent work and achievements.
- **Experience Timeline**: Clear presentation of professional history and education.
- **Responsive Navigation**: Easy-to-use menu that works on all devices.
- **Modern UI**: Clean typography and balanced layout for professional appeal.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Personal_website/`
3. Open `index.html` in your web browser.
