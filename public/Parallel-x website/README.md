# Parallel-X Parallax Website

## Description
A visually stunning demonstration of the parallax scrolling effect. This project features multiple layers of depth (hills, trees, leaves) that move at different speeds as the user scrolls, creating a beautiful 3D-like experience in a 2D environment.

## Technologies Used
- HTML5
- CSS3 (Fixed Positioning & Layers)
- JavaScript (Scroll Event Tracking)

## Features
- **Multi-layered Parallax**: Features over 7 layers of background and foreground elements.
- **Smooth Interaction**: Uses JavaScript to translate scroll position into element movement.
- **Nature Theme**: Beautifully designed with hills, plants, and trees for a serene look.
- **Dynamic Header**: Includes a responsive navigation bar that integrates with the parallax effect.
- **Performance Optimized**: Carefully managed scroll events for a smooth user experience.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Parallel-x website/`
3. Open `parallal.html` in your web browser.

## Folder Structure
```text
Parallel-x website/
 ├── *.png            # Layer assets (hills, trees, plants, leaves)
 ├── parallal.html    # Website structure
 ├── parallal.js      # Scroll interaction logic
 └── parallal.css     # Layering and visual styling
```
