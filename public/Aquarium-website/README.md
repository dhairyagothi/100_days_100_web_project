## ✨ Features

- **Sticky Header & Nav** — clean top bar with store branding and navigation links
- **Hero Section** — full-width ocean background image with centered text overlay
- **Product Cards Grid** — responsive CSS Grid layout using `auto-fit` and `minmax`
- **Hover Effects** — cards lift with `translateY` on hover
- **Mobile Responsive** — grid adapts to any screen width automatically
- **No JavaScript** — pure HTML + CSS only

## 🧠 Concepts Practiced

- CSS Grid with `auto-fit` + `minmax` for responsive layouts
- `object-fit: cover` for consistent image sizing
- CSS `transition` and `transform` for hover effects
- `text-shadow` for hero text legibility over images
- `box-shadow` for card depth
- Semantic HTML structure (`header`, `nav`, `section`, `footer`)
