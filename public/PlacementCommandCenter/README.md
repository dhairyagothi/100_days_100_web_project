# Placement Command Center

A centralized dashboard for students preparing for placements.

## Features

- Track company applications
- Monitor interview progress
- Track job offers and rejections
- Coding progress tracker
- Resume version tracker
- Dashboard statistics
- Dark / Light mode
- LocalStorage persistence
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Data Stored

### Applications

- Company Name
- Application Status

### Coding Tracker

- Leetcode Solved
- Contest Rating
- Weekly Problems

### Resume Tracker

- Resume Versions

## LocalStorage Keys

- placementCompanies
- placementCoding
- placementResume
- placementTheme

## How To Run

Open:

public/PlacementCommandCenter/index.html

or run:

python3 -m http.server 8000

and visit:

http://localhost:8000/public/PlacementCommandCenter/index.html
