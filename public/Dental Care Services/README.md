# Dental Care Services Website

## Description
A comprehensive, multi-page professional website for a dental clinic. This project showcases a clean, trustworthy design with sections for services, appointments, pricing, and team information, providing a complete online presence for healthcare providers.

## Technologies Used
- HTML5
- CSS3 (SCSS)
- JavaScript (jQuery)
- Bootstrap 5 (via lib)
- Font Awesome

## Features
- **Multi-page Navigation**: Includes About, Contact, Service, Pricing, Team, and Testimonial pages.
- **Appointment Booking**: A dedicated page for users to schedule visits.
- **Responsive Layout**: Built with Bootstrap to ensure compatibility across all devices.
- **Dynamic Elements**: Includes testimonials, service cards with icons, and pricing tables.
- **Professional Gallery**: Showcases the clinic environment and team.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Dental Care Services/Setup/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Dental Care Services/
 └── Setup/
      ├── css/        # Compiled CSS
      ├── img/        # Website images and icons
      ├── js/         # Main website logic
      ├── lib/        # Third-party libraries (Bootstrap, OwlCarousel, etc.)
      ├── scss/       # Source SCSS files
      ├── index.html  # Landing page
      └── *.html      # Sub-pages (About, Contact, Appointment, etc.)
```
