# Memory Matching Game

## Description
A classic browser-based memory matching game. Players flip cards to reveal symbols and try to find matching pairs in the shortest time or fewest moves. This project demonstrates DOM manipulation, state management, and CSS animations.

## Technologies Used
- HTML5
- CSS3 (Grid Layout & Transitions)
- JavaScript (Vanilla)

## Features
- **Interactive Grid**: Dynamically generated card layout.
- **Card Flip Mechanics**: Smooth CSS transitions for card reveal.
- **Match Logic**: Automatic detection of matching and non-matching pairs.
- **Score Tracking**: Real-time counter for successful matches.
- **Reset Capability**: Play again after completing the game.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/MemoryGame/`
3. Open `index.html` in your web browser.
