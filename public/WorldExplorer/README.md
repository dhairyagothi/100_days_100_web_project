# 🌍 Interactive World Explorer

An elegant, responsive, and interactive **World Explorer** web application that lets users discover countries around the globe. Search, filter, sort, and explore detailed information including flags, capitals, populations, currencies, languages, timezones, and more—all inside a beautiful modern interface.

### 🌎 Country Explorer
- Browse countries using beautiful responsive cards
- High-quality country flags

- Interactive country detail modal

### 🔍 Smart Search
- Real-time country search
- Instant filtering while typing
- Clear search button

Sort countries by:

# 🖥️ How to Run

### Clone the repository

```bash
git clone https://github.com/100_days_100_web_project.git
```

### Navigate into the project

```bash
cd public
cd World-Explorer
```

### Open

Simply open **index.html** in your preferred browser.

No installation or dependencies are required.
