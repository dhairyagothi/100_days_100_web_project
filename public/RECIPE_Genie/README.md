# RECIPE Genie

## Description
A modern, AI-powered recipe discovery application built with Next.js and Tailwind CSS. RECIPE Genie helps users find perfect recipes by analyzing ingredients and preferences, providing a seamless and intuitive cooking inspiration experience.

## Technologies Used
- Next.js 14 (App Router)
- React
- Tailwind CSS
- TypeScript
- Lucide React (for icons)

## Features
- **AI-Driven Discovery**: Personalized recipe recommendations based on user input.
- **Modern Responsive UI**: A sleek, dark-themed interface optimized for all devices.
- **Fast Performance**: Leverages Next.js server-side rendering and static optimization.
- **Dynamic Routing**: Dedicated pages for detailed recipe information.
- **Search & Filter**: Effortlessly find specific dishes or cuisines.

## Setup Instructions
1. Navigate to the project folder: `public/RECIPE_Genie/my-project/`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000` in your browser.
