# 🎨 Pixel Art Creator

A feature-rich, browser-based pixel art drawing tool with a stunning glassmorphism dark theme.

## ✨ Features

- **4 Drawing Tools**: Draw (pencil), Fill Bucket, Eraser, Eyedropper
- **Adjustable Grid**: 8×8, 16×16, 32×32, 48×48 pixel canvases
- **Brush Size**: 1–5px brush thickness
- **Color Palette**: 20 default colors + add custom colors
- **Undo / Redo**: 50-step history (Ctrl+Z / Ctrl+Y)
- **Templates**: Heart ❤️, Star ⭐, Smiley 😊, Rainbow 🌈
- **Mini Preview**: Live preview of your artwork
- **Recent Colors**: Last 10 used colors
- **Download PNG**: Export at 16× scale (256px for 16×16)
- **Grid Toggle**: Show/hide pixel grid lines
- **Live Stats**: Pixels drawn, colors used, undo steps
- **Keyboard Shortcuts**: D (Draw), F (Fill), E (Erase), I (Eyedrop)
- **Touch Support**: Works on mobile & tablet
- **Responsive Design**: Adapts to all screen sizes

## 🛠️ Technologies

- HTML5 Canvas API
- Vanilla CSS (Glassmorphism dark theme)
- Vanilla JavaScript (ES6+, IIFE pattern)
- Google Fonts (Outfit)

## 🚀 How to Run

Simply open `index.html` in any modern browser. No dependencies or build steps needed!

## 🎮 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `D` | Draw tool |
| `F` | Fill bucket |
| `E` | Eraser |
| `I` | Eyedropper |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
