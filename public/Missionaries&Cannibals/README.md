# Missionaries and Cannibals Puzzle

## Description
A classic logic puzzle game where the objective is to transport three missionaries and three cannibals from the left bank to the right bank of a river. The player must navigate the boat across the river while adhering to strict safety rules.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Rules of the Game
1. The boat can carry a maximum of two people at a time.
2. The boat must have at least one person to cross the river.
3. If at any point the cannibals outnumber the missionaries on either bank, the cannibals will eat the missionaries, and the game is over!

## Features
- **Interactive Gameplay**: Click to select characters and move them to/from the boat.
- **Drag and Drop Support**: Alternatively, use drag-and-drop to move characters.
- **State Validation**: Automatic checking for game-over conditions (missionaries outnumbered) and win conditions (all moved to the right bank).
- **Difficulty Feedback**: Real-time messages guiding the player on boat capacity and illegal moves.
- **Reset Functionality**: Start over at any time with the "Start/Reset" button.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/Missionaries&Cannibals/`
3. Open `index.html` in your web browser.
