# Flip Clock

A playful digital flip clock with a live time display, date and day footer, and built-in theme swatches for changing the visual style.

## Features

- Live hour, minute, and second display
- Current date and weekday
- Color theme picker with multiple presets
- Clean single-screen layout

## How to Use

1. Open the app in a browser.
2. Watch the clock update in real time.
3. Pick a color swatch to change the theme.

## Files

- `index.html` - Clock layout and controls
- `style.css` - Visual styling
- `script.js` - Time updates and theme switching

## Notes

- The clock updates every second with the current system time.
- Themes are applied with CSS custom properties.
