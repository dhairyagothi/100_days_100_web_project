# Password Manager

## Description
A secure and user-friendly password management application for the web. It allows users to store, manage, and quickly access their login credentials for various websites, helping maintain strong security habits without the need to memorize every password.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (DOM Manipulation & Local Storage)

## Features
- **Secure Storage**: Saves passwords locally in the browser using Local Storage for privacy.
- **Easy Retrieval**: Search and find passwords for specific sites quickly.
- **Add/Edit/Delete**: Full CRUD functionality for managing your password entries.
- **Copy to Clipboard**: Quick-copy icons to instantly copy usernames or passwords.
- **Clean Interface**: Focused on security and ease of use.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/password manager/`
3. Open `index.html` in your web browser.
