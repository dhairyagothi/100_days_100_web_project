# 2048 Game

## Description
A browser-based implementation of the addictive 2048 puzzle game. The objective is to slide numbered tiles on a grid to combine them to create a tile with the number 2048. This project showcases complex grid logic, array manipulation, and responsive event handling.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- **Smooth Tile Movement**: Clean transitions as tiles slide and merge.
- **Score System**: Real-time tracking of your current score.
- **Dynamic Grid**: A 4x4 grid where new tiles appear after every move.
- **Keyboard Interaction**: Fully playable using arrow keys.
- **Game Result**: Displays a message when the user wins or when no more moves are possible.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/2048_game/`
3. Open `index.html` in your web browser.
