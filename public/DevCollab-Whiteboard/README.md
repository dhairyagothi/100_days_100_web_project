# DevCollab Whiteboard

An interactive collaborative-style whiteboard built using HTML, CSS, JavaScript, and Canvas API.

## Features

- Draw freely on canvas
- Adjustable brush size
- Color picker
- Save canvas as image
- Clear board functionality
- Responsive fullscreen UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## How to Run

1. Open index.html
2. Start drawing

## Future Improvements

- Real-time collaboration with WebSockets
- Multiple rooms
- Undo/Redo
- Shape tools
