# 🧠 Memory Card Game

Memory Card Game is an interactive browser-based game where players test their memory by matching pairs of cards. The project demonstrates JavaScript game logic, DOM manipulation, and responsive web design while providing an enjoyable learning experience.

---

## ✨ Features

- 🃏 Flip cards to reveal hidden symbols
- 🎯 Match identical card pairs
- ⏱️ Timer and move counter (if available)
- 🏆 Win detection
- 🔄 Restart game option
- 📱 Responsive design
- 🎨 Smooth animations and transitions

## ▶️ Gameplay

1. Start the game.
2. Click on a card to reveal it.
3. Flip another card to find its matching pair.
4. If both cards match, they remain visible.
5. If they don't match, they flip back.
6. Continue until all pairs are matched.
