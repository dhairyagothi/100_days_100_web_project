# 🎬 Movie Explorer Pack

Movie Explorer Pack is a modern web application that allows users to discover, browse, and explore movies through an intuitive and responsive interface. The project showcases movie information, genres, ratings, and search capabilities while providing an engaging user experience.

---

## ✨ Features

- 🎬 Browse popular movies
- 🔍 Search movies by title
- ⭐ View ratings and movie details
- 🎭 Explore different genres
- 📱 Fully responsive interface
- 🎨 Modern and user-friendly UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd "Movie Explorer Pack"
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code
