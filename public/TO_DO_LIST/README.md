# TaskFlow

TaskFlow is a modern, client-side to-do list app built with HTML, CSS, and JavaScript. It helps users manage daily tasks with a clean interface, local persistence, and a few productivity-focused extras.

## Features

- Add, edit, complete, and delete tasks
- Filter tasks by status and category
- Live task statistics
- Multiple visual themes
- Drag-and-drop workflow states
- Toast notifications
- LocalStorage persistence
- PDF export for saved tasks

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
- jsPDF

## How To Run

1. Open `public/TO_DO_LIST/todolist.html` in a browser.
2. Add some tasks.
3. Try the filters, theme toggle, drag-and-drop workflow, and export actions.
