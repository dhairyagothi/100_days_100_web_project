# Advanced AI To-Do List

A highly advanced, modern To-Do List web application built with HTML, CSS, and Vanilla JavaScript.
It goes beyond a standard To-Do list by incorporating a stunning glassmorphic UI and simulated AI features that make task management much more interactive.

## ✨ Key Features

- **Daily AI Briefing**: Dynamically generates a summary of active and urgent tasks based on their due dates.
- **Smart Task Breakdown (Magic Wand)**: A simulated AI feature that instantly breaks down complex tasks into smaller, actionable sub-tasks.
- **Floating Chatbot Assistant**: An interactive UI where users can ask for their most urgent tasks or a status summary.
- **Full Date Management**: Users can assign exact target dates to tasks, which format elegantly in the UI.
- **Advanced Sorting & Filtering**: Sort by Date (Earliest/Latest), Recently Added, and filter by All/Active/Completed.
- **Data Persistence**: Fully utilizes LocalStorage to save states securely.
- **Responsive & Modern UI**: Built with CSS Grid/Flexbox, CSS custom variables, and sleek glassmorphism effects.

## 🛠 Technologies Used

- HTML5
- Vanilla CSS3 (Variables, Animations, Glassmorphism)
- Vanilla JavaScript (ES6, DOM Manipulation, LocalStorage)

## How to use

Simply open `index.html` in any modern web browser. No local server required!
