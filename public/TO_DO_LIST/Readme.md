# 🚀 TaskFlow: Modern To-Do List Web Application

## 📌 Description

**TaskFlow** is a modern, responsive, and feature-rich To-Do List web application built to enhance productivity with a clean UI and smooth user experience.

This upgraded version introduces **advanced task management features**, **dynamic theme switching**, **PDF export functionality**, **task filtering**, and a **real-time productivity dashboard**.

---

## ✨ Features

### 📝 Task Management

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Inline task interaction UI
* Category-based task tagging (Work, Personal, Fitness, etc.)

---

### 📊 Productivity Dashboard

* Total tasks counter
* Completed tasks counter
* Pending tasks counter
* Real-time progress percentage
* Animated progress bar

---

### 🎯 Task Filtering System

* View all tasks
* Filter by:

  * Pending tasks
  * Completed tasks
  * Categories (Work, Personal, Urgent, Fitness, Misc)

---

### 🎨 Dynamic Theme System

* Multiple modern themes:

  * 🌅 Sunset
  * 🌊 Ocean
  * 🌲 Forest
  * 🌌 Midnight
  * ✨ Aurora
* Smooth transitions between themes
* Persistent UI color updates

---

### 📄 PDF Export & Documents System

* Export task list as PDF
* Auto-generated document name with timestamp
* Saved Documents section:

  * View PDF
  * Download PDF
  * Delete saved files

---

### 💻 UI/UX Enhancements

* Fully responsive design (mobile + desktop)
* Glassmorphism-inspired UI
* Smooth animations and transitions
* Modern navbar with tab navigation
* Improved empty states
* Better spacing and typography

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Modern Variables + Responsive Design)
* JavaScript (ES6+)
* jsPDF (PDF generation)
* Font Awesome (Icons)
* Google Fonts

## ⚙️ Installation / Setup

### 1. Clone the repository

```bash
git clone <repository-link>
```

### 2. Navigate to project folder

```bash
cd TaskFlow
```

### 3. Run the project

Simply open:

```
index.html
```

in your browser.

---

## 📖 Usage

* Add tasks using the input field
* Select a category (optional)
* Click **Add Task**
* Mark tasks as complete/incomplete
* Filter tasks using the filter bar
* Track progress using the stats dashboard
* Switch themes using theme buttons
* Export tasks as PDF
* Manage saved documents in the Documents tab
