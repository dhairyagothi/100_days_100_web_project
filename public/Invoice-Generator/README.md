# Day 168 - Invoice / Bill Generator

A professional Invoice/Bill Generator that works entirely in the browser no backend required.

## Features

- Add/remove line items with description, quantity, and unit price
- Auto-calculated subtotal, tax (GST %) and discount %
- Clean invoice preview with company & client details
- Invoice number and date management
- Print & Save as PDF support
- Fully responsive design

## Tech Stack

- HTML
- CSS
- JavaScript

## Folder Structure
Day168_Invoice_Generator/  
├── index.html  
├── style.css  
└── script.js

## How to Use

1. Fill in your company and client details
2. Add line items with quantity and price
3. Set tax/discount if needed
4. Click **Generate Invoice**
5. Print or Save as PDF
