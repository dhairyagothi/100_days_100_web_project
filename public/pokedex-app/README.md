# 📖 Pokedex App

Pokedex App is an interactive web application that allows users to explore Pokémon information using the PokéAPI. Users can search for Pokémon, view their abilities, types, stats, images, and other details through a clean and responsive interface.

---

## ✨ Features

- 🔍 Search Pokémon by name
- 🧬 View Pokémon types and abilities
- 📊 Display base stats
- 🖼️ Official Pokémon artwork
- ⚡ Fast API-powered search
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- PokéAPI

---

## 🌐 API Used

**PokéAPI**

https://pokeapi.co/

Provides Pokémon data including:

- Pokémon information
- Types
- Abilities
- Base Stats
- Official Artwork

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd pokedex-app
```

Run locally

- Open `index.html`
- OR use Live Server in VS Code

---

## ▶️ Usage

1. Launch the application.
2. Enter a Pokémon name.
3. Click Search.
4. View Pokémon information including stats, abilities, and image.
