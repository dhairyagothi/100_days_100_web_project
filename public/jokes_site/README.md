# Jokes Site

## Description
A simple and fun website that delivers a fresh joke with every click. It uses a public joke API to keep the content updated and entertaining.

## Technologies Used
- HTML5
- CSS3 (Flexbox)
- JavaScript (Fetch API)

## Features
- **Random Jokes**: Fetches random jokes from an external API.
- **Interactive UI**: Click a button to get a new joke instantly.
- **Clean Design**: Minimalist layout focused on readability.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/jokes_site/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
jokes_site/
 ├── index.html       # Main structure
 ├── script.js        # API fetching logic
 └── style.css        # Layout styling
```
