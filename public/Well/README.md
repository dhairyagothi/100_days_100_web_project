# ✨ Interactive Particle Flow Simulator

> **A mesmerizing browser-based particle simulation where hundreds of particles dynamically respond to mouse movement, creating smooth flowing trails and interactive visual effects using the HTML5 Canvas API.**

# 🌌 Overview

**Interactive Particle Flow Simulator** is a lightweight yet visually captivating web application that demonstrates real-time particle physics using the HTML5 Canvas API.

Hundreds of particles move freely across the screen, reacting to the user's mouse position with smooth attraction forces, creating elegant motion trails and a dynamic interactive experience.

Everything runs entirely in the browser without any external libraries.

---

# ✨ Features

## 🌠 Real-Time Particle Simulation

The application generates:

* 500 animated particles
* Independent particle movement
* Random initial velocities
* Continuous motion
* Smooth animation loop

---

## 🖱️ Mouse Interaction

Move your cursor across the screen to:

* Attract nearby particles
* Influence particle velocity
* Create beautiful flowing motion
* Generate unique movement patterns

Particles automatically stop following when the mouse leaves the screen.

---

## 🎨 Motion Trail Effect

Instead of clearing the canvas every frame, the application uses a transparent overlay to create:

* Smooth fading trails
* Motion blur effect
* Elegant particle paths
* Fluid visual animations

---

## ⚡ HTML5 Canvas Rendering

The simulation leverages the power of the **Canvas API** to provide:

* High-performance rendering
* Real-time animations
* Efficient particle updates
* Smooth 60 FPS experience (device dependent)

---

## 🌌 Full-Screen Experience

Designed for an immersive experience with:

* Full-screen canvas
* Responsive viewport
* Minimalist interface
* Dark background for enhanced visuals

---

## 🔄 Continuous Animation Loop

Built using `requestAnimationFrame()` for:

* Optimized performance
* Smooth animations
* Efficient rendering
* Browser-friendly updates
