# Habit Tracker

A modern Habit Tracker web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Add and delete habits
- Mark habits complete for the current day
- Track streak counts for individual habits and global completion
- Save habits and progress using `localStorage`
- Dynamic DOM updates and smooth UI animations
- Responsive layout for desktop and mobile
- Empty state handling with helpful prompts
- Productivity-style progress summary

## Project structure

- `index.html` — entry page for the Habit Tracker app
- `style.css` — theme, layout, and animation styles
- `script.js` — habit state management, localStorage persistence, and DOM rendering

## Usage

1. Open `index.html` in the browser.
2. Add habits using the input field and the Add button.
3. Tap the completion button to mark habits complete for today.
4. Delete habits with the trash button.
5. All data is stored in `localStorage` and restored on reload.
