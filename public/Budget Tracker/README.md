# Budget Tracker

## Description
A practical personal finance tool to help users track their income and expenses. It provides a clear overview of the current balance and a detailed history of transactions, making financial management easy.

## Technologies Used
- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM Manipulation & State Management)

## Features
- **Transaction Entry**: Add income and expense items with descriptions and amounts.
- **Balance Overview**: Automatically calculates and displays total balance, income, and expenses.
- **History List**: A scrollable list of all past transactions with delete functionality.
- **Visual Cues**: Color-coded amounts (green for income, red for expenses).

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Budget Tracker/`
3. Open `index.html` in your web browser.
