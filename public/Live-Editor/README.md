# 💻 Live Editor

Live Editor is an interactive browser-based code editor that allows users to write and preview HTML, CSS, and JavaScript in real time. It provides an instant development environment for experimenting with front-end code without requiring any setup.

---

## ✨ Features

- 💻 Live HTML editor
- 🎨 Real-time CSS styling
- ⚡ Instant JavaScript execution
- 👀 Live preview panel
- 📱 Fully responsive interface
- 🚀 Fast and lightweight experience

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Live-Editor
```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Write HTML code in the editor.
3. Add CSS styles.
4. Write JavaScript logic.
5. View the output instantly in the preview panel.
