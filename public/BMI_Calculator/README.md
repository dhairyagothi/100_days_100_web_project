# BMI Calculator

## Description
A feature-rich web application that calculates Body Mass Index (BMI) and provides personalized health insights. It supports both metric and imperial units, making it accessible to a global audience. The app also includes data visualization to help users understand where they stand in terms of health categories.

## Technologies Used
- HTML5
- CSS3 (Custom Grid & Flexbox)
- JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) (Data Visualization)
- [Boxicons](https://boxicons.com/) (Iconography)

## Features
- **Dual Unit Support**: Calculate BMI using Centimeters/Feet for height and Kilograms/Pounds for weight.
- **Dynamic Categorization**: Instant feedback on whether the user is Underweight, Ideal, Overweight, or Obese.
- **Health Tips**: Personalized advice based on the calculated BMI result.
- **Data Visualization**: Integrated chart to visualize BMI ranges and the user's relative position.
- **Responsive Interface**: Clean, modern design that works across desktop and mobile devices.
- **Reference Table**: Includes a standard BMI category table for quick reference.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/BMI_Calculator/`
3. Open `index.html` in your web browser.
