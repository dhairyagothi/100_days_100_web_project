# Interactive Periodic Table

## Description
A comprehensive and interactive periodic table of elements. This educational tool provides a detailed view of chemical elements, organized by their atomic number and properties, with dynamic information retrieval for students and science enthusiasts.

## Technologies Used
- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (Dynamic Rendering & Data Visualization)

## Features
- **Full Periodic Layout**: Correctly displays all elements in their standard groups and periods.
- **Detailed Element Info**: Click on any element to see atomic mass, number, symbol, and more.
- **Color Coding**: Elements are color-coded based on their categories (Metals, Noble Gases, etc.).
- **Responsive Grid**: Adapts the complex table layout for various screen sizes.
- **Interactive Hover Effects**: Highlights related elements or properties on hover.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Periodic Table/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Periodic Table/

 ├── script.js        # Element data and interaction logic
 └── styles.css       # Table grid and color styling
```
