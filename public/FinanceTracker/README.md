# Finance Tracker

## Description
A comprehensive personal finance dashboard that allows users to monitor their financial health in one place. It features interactive charts, balance tracking, and detailed transaction history to help users make informed financial decisions.

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript (Charts.js & DOM Manipulation)

## Features
- **Interactive Dashboard**: Visualizes income vs. expenses using dynamic charts.
- **Transaction History**: Keeps a detailed log of all financial activities.
- **Balance Tracking**: Automatically updates the current balance based on transactions.
- **Modern UI**: Built with a sleek, dark-themed interface using Tailwind CSS.
- **Responsive Design**: Works seamlessly across mobile and desktop devices.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/FinanceTracker/`
3. Open `index.html` in your web browser.
