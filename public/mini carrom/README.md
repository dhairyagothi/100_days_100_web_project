# 🎯 Mini Carrom Game

An engaging browser-based Carrom game that recreates the classic tabletop experience using modern web technologies. Designed with smooth gameplay mechanics, responsive controls, and an attractive user interface, this project demonstrates the power of JavaScript for creating interactive gaming experiences.

## 🚀 Overview

Mini Carrom is a lightweight web application that allows users to enjoy a digital version of the popular Carrom board game directly in their browser. The project focuses on user experience, game physics, and responsive design.

## ✨ Features

- 🎮 Interactive Carrom gameplay
- ⚡ Smooth and responsive controls
- 🎨 Modern and visually appealing UI
- 📱 Mobile-friendly and responsive design
- 🔄 Real-time game interactions
- 🏆 Score tracking system
- 🚀 Fast loading and lightweight implementation

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

## 🔧 Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project directory

```bash
cd Mini-Carrom
```

3. Open `index.html` in your preferred browser.

## 🎮 Usage

- Launch the game in your browser.
- Use the game controls to aim and strike.
- Pocket the pieces to score points.
- Challenge yourself to achieve the highest score possible.
