# Mini Carrom Game

## 🏆 Project Overview

Mini Carrom Game is a browser-based two-player game inspired by the traditional board game Carrom. Players take turns controlling a striker to pocket coins and compete for the highest score using simple keyboard or mouse controls.

The project is built entirely using HTML, CSS, and JavaScript, making it lightweight and easy to run without any external dependencies.

---

## ✨ Features

* Two-player gameplay
* Smooth striker controls
* Coin collision mechanics
* Score tracking system
* Turn-based gameplay
* Winning condition detection
* Responsive game interface
* Simple and interactive UI

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## 🎮 How to Play

1. Open the game in your browser.
2. Player 1 starts by controlling the striker.
3. Aim and shoot the striker toward the coins.
4. Pocket coins to earn points.
5. Turns alternate between players.
6. Continue until all coins are pocketed or the game-ending condition is met.
7. The player with the highest score wins.
