# FlashLearn

A modern Flashcard Learning Application built using HTML, CSS, and JavaScript.

## Features

- Create Flashcards
- Edit Flashcards
- Delete Flashcards
- Subject Categorization
- Search Functionality
- Study Mode
- Card Flip Animation
- Shuffle Cards
- Progress Tracking
- Study Streak Counter
- Dark/Light Theme
- Import/Export JSON
- Local Storage Support

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## How to Run

1. Open index.html
2. Start creating flashcards
