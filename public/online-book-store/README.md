# 📚 Online Book Store

Online Book Store is a responsive web application that provides a modern interface for browsing, exploring, and discovering books online. The project demonstrates an e-commerce inspired UI where users can view book collections, categories, featured books, and detailed information in a clean and user-friendly layout.

---

## ✨ Features

- 📚 Browse book collections
- 🔍 Search books by title or category
- ⭐ Featured books section
- 📖 Book details and descriptions
- 📱 Fully responsive design
- 🎨 Modern and attractive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd online-book-store
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Browse available books.
3. Search for books using the search functionality (if available).
4. Explore featured books and categories.
5. View detailed information about selected books.
