# Escape The Lab

Escape The Lab is a story-driven escape-room game where you explore clues, unlock a terminal, and solve hidden codes before the facility seals permanently.

## Features

- Interactive hotspot clues
- Terminal-based puzzle progression
- Countdown timer with failure state
- Layered clue unlocking sequence
- Escape condition driven by the final code

## How to Play

1. Click **Start** to enter the lab.
2. Inspect the visible hotspots for clues.
3. Open the terminal and type the correct codes.
4. Unlock every clue and escape before time runs out.

## Files

- `index.html` - Game layout and UI
- `style.css` - Visual styling
- `script.js` - Game logic, timer, and clue flow

## Notes

- The experience is designed as a single-screen browser puzzle.
- Progress advances through clue-gated hotspot reveals.
