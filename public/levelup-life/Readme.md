# 🚀 LevelUp Life

**LevelUp Life** is a highly-polished, gamified behavioral engine and productivity dashboard. It combines a ⚡ cyberpunk aesthetic with actionable productivity tools, allowing users to earn XP, level up, track daily streaks, and utilize a Pomodoro focus timer—all within a single, state-driven dashboard.



---

## 🌟 Features

- 🎮 **Gamified Task System**: Add tasks with distinct difficulty levels (EASY, MID, HARD) to earn varying amounts of XP.
- 📈 **XP & Level Engine**: Visual progression with an animated XP bar and a dynamic leveling system featuring a dedicated Level Up modal queue.
- 🔥 **Streak Tracker**: Automatic daily tracking to monitor consistency, including milestone bonuses (3, 7, 14, 30 days) and a best streak record.
- ⏳ **Focus Core (Pomodoro)**: Integrated 25/50 minute timer that rewards XP upon session completion.
- 🏆 **Achievement System**: Unlockable badges for completing the first task, reaching a 3-day streak, and hitting Level 5.
- 💾 **Persistent State**: Automatic local storage saving ensures your stats, themes, and tasks are always retained.
- 🎨 **Theme Engine**: Smooth toggling between a sleek Dark/Neon Cyberpunk mode and a clean Light mode.

---

## 🛠️ Technologies Used

- 🌐 HTML5  
- 🎨 CSS3 (Vanilla, CSS Variables, Animations)  
- ⚙️ JavaScript ES6 (DOM Manipulation, LocalStorage)  

---

## ▶️ How to Run

1. 📂 Open `index.html` in a modern web browser  
2. 👤 Enter your username and select an avatar  
3. 🚀 Start adding tasks, using the focus timer, and leveling up!
