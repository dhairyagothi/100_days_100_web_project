# 🃏 Memory Card Machine Game

Memory Card Machine Game is an interactive browser-based card matching game that challenges players to improve their memory by finding matching pairs of cards. With smooth animations and responsive gameplay, it provides an engaging experience while demonstrating JavaScript game development concepts.

---

## ✨ Features

- 🃏 Interactive card-flipping mechanics
- 🧠 Memory-based gameplay
- 🎯 Match identical card pairs
- 🏆 Automatic win detection
- 🔄 Restart game option
- 📱 Fully responsive design
- 🎨 Smooth animations and modern interface

## ▶️ Gameplay

1. Launch the game.
2. Click a card to reveal it.
3. Reveal another card and try to find its matching pair.
4. Matching cards remain visible.
5. Non-matching cards flip back automatically.
6. Match all pairs to complete the game.
