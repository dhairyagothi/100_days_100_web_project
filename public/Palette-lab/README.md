# 🎨 Palette Lab

Palette Lab is an interactive web application that allows users to create, explore, and experiment with beautiful color palettes. It is designed for developers, designers, and UI/UX enthusiasts who want to generate harmonious color combinations for websites, applications, and creative projects.

---

## ✨ Features

- 🎨 Generate beautiful color palettes
- 🌈 Explore different color combinations
- 📋 Copy color codes with one click
- 🔄 Random palette generation
- 📱 Fully responsive interface
- ⚡ Smooth and modern user experience

---

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd Palette-lab
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Generate a new color palette.
3. Browse available color combinations.
4. Copy any color code with a single click.
5. Use the colors in your design or development projects.
