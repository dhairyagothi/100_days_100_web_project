# 🌌 Solar System Explorer

Solar System Explorer is an interactive web application that allows users to explore the planets and other celestial bodies of our solar system through an engaging and visually appealing interface. The project is designed to make learning astronomy fun and interactive.

---

## ✨ Features

- 🪐 Explore all major planets of the Solar System
- 🌍 Learn basic information about each planet
- 🌞 Interactive and visually rich interface
- 📱 Fully responsive design
- ⚡ Lightweight and fast
- 🎨 Smooth animations and transitions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd "Solar System Explorer"
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Launch the application.
2. Browse through the planets of the Solar System.
3. Click or interact with planets to view their details.
4. Explore facts and information about each celestial body.
