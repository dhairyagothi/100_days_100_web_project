# 🎲 Pig Game

Pig Game is a fun two-player dice game built using HTML, CSS, and JavaScript. Players take turns rolling a dice to accumulate points while deciding whether to continue rolling or hold their current score. The first player to reach the winning score wins the game.

---

## ✨ Features

- 🎲 Interactive dice rolling
- 👥 Two-player gameplay
- 📈 Live score tracking
- ⏸️ Hold current score functionality
- 🔄 New game reset option

## 🎮 How to Play

1. Two players play alternately.
2. Roll the dice to earn points.
3. Rolling any number except **1** adds to your current score.
4. Rolling **1** resets the current score and passes the turn.
5. Click **Hold** to save your current score.
6. The first player to reach the winning score wins the game.
