# Pig Game

## Description
A classic two-player dice game where players compete to reach a target score (usually 100). The game tests risk management and luck, as players must decide whether to "Hold" their current round's points or keep rolling the dice at the risk of losing it all.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Keyframe Animations)
- JavaScript (Game State Management & DOM Manipulation)

## Features
- **Two-Player Support**: Alternate turns between Player 1 and Player 2.
- **Roll Dice Mechanism**: Generates a random number from 1 to 6 with visual dice updates.
- **Hold Logic**: Add current round points to the total score and switch turns.
- **Winner Detection**: Automatically identifies and highlights the winner when the target score is reached.
- **Reset Functionality**: Start a new game anytime with a single click.
- **Dynamic UI**: Real-time updates for active players and scores.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/pig_game/`
3. Open `index.html` in your web browser.
