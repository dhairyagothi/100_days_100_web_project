# 🚨 Incident Communication War Room

Incident Communication War Room is a web-based incident management dashboard that helps teams communicate service disruptions efficiently. Users can create incidents, classify severity levels, publish status updates, and maintain a real-time incident timeline for transparent communication.

---

## ✨ Features

- 🚨 Create new incidents
- ⚠️ Assign incident severity levels
- 📢 Publish live status updates
- 📅 Chronological incident timeline
- 📊 Public status dashboard
- 📱 Responsive user interface
- 🎨 Clean and intuitive design

---

## ▶️ Usage

1. Launch the application.
