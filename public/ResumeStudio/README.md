# ResumeStudio

## Description
A fast and intuitive online resume builder. ResumeStudio allows users to quickly generate professional resumes by inputting their personal details, education, and work experience. It offers real-time preview and easy exporting.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Responsive Design)
- JavaScript (DOM Manipulation & Real-time Form Handling)

## Features
- **Real-time Preview**: See your resume update instantly as you type.
- **Dynamic Sections**: Easily add or remove education and experience entries.
- **Clean Templates**: Generates resumes with a modern, professional layout.
- **Print to PDF**: Built-in functionality to print or save the final resume as a PDF.
- **User-friendly Form**: A straightforward interface for inputting career data.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/ResumeStudio/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
ResumeStudio/
 ├── index.html       # Resume builder interface
 ├── script.js        # Form handling and real-time preview logic
 └── style.css        # Visual styling for both the form and the resume
```
