# Nykaa Clone

## Description
A comprehensive frontend replica of the Nykaa e-commerce platform. This project focuses on recreating the complex and vibrant user interface of India's leading beauty and fashion destination, including product grids, carousels, and navigation systems.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Data-driven UI Rendering)

## Features
- **Dynamic Product Grids**: Renders product lists dynamically from structured data files.
- **Brand Showcases**: Dedicated sections for "Top Brands" and "Hard to Resist Deals".
- **Responsive Navigation**: Includes a detailed navbar with categories and search functionality.
- **Interactive Carousels**: Showcases promotional banners and product highlights.
- **Modern Aesthetic**: Mimics Nykaa's signature pink and white theme for a premium feel.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Nykaa-clone/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Nykaa-clone/
 ├── public/          # Image assets and icons
 ├── index.html       # Main landing page structure
 ├── script.js        # Core UI interaction logic
 ├── style.css        # Layout and component styling
 └── *data*.js        # Modular data files for products and brands
```
