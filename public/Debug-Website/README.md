# Debug Quest - Level 2

## Description
An interactive and intentionally chaotic web application designed as a "Debug Quest". This project challenges users to find hidden keys, trigger glitches, and navigate through a series of "confounding catastrophes". It features high-energy animations, sound effects, and hidden messages inspired by cyberpunk and horror aesthetics.

## Technologies Used
- HTML5
- CSS3 (Advanced Animations, Glitch Effects, & Filters)
- JavaScript (Complex DOM Manipulation, Event Handling, & Audio API)

## Features
- **Glitch UI**: Intentionally distorted and glitchy interface elements to challenge the user.
- **Interactive Cards**: Various cards like "Ghostly Revelation", "Bouncing Bamboozler", and "Safari Adventure" with unique behaviors.
- **Sound & Video Integration**: Uses multiple audio tracks and video backgrounds to create an immersive (and sometimes startling) experience.
- **Hidden Secrets**: Challenges users to find hidden keys and data fragments within the source code and UI.
- **Chaotic Effects**: Features screen distortions, bouncing elements, and "Fatal Error" (BSOD) simulations.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Debug-Website/`
3. Open `index.html` in your web browser.
4. **Warning**: Contains loud sounds and flashing effects.
