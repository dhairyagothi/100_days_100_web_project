# ♛ N-Queen Visualizer

N-Queen Visualizer is an interactive web application that demonstrates the classic **N-Queen Problem** using backtracking. The project visually illustrates how queens are placed on a chessboard while ensuring that no two queens attack each other.

---

## ✨ Features

- ♛ Interactive N-Queen visualization
- 🧠 Backtracking algorithm demonstration
- 📊 Step-by-step queen placement
- ⚡ Real-time solution generation
- 📱 Fully responsive interface
- 🎨 Clean and intuitive UI

## 📖 About the Algorithm

The **N-Queen Problem** is a classic backtracking problem.

The objective is to place **N queens** on an **N × N chessboard** such that:

- No two queens share the same row.
- No two queens share the same column.
- No two queens share the same diagonal.

The application uses the **Backtracking Algorithm** to recursively search for valid queen placements.
