# N-Queen Solver Visualizer

## Description
An educational tool that visualizes the backtracking algorithm used to solve the classic N-Queen problem. It demonstrates how $N$ queens can be placed on an $N \times N$ chessboard such that no two queens threaten each other, providing a step-by-step visual representation of the decision-making process.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Chessboard Styling)
- JavaScript (Backtracking Algorithm & Async Visualization)

## Features
- **Dynamic Board Size**: (If implemented) Visualize solutions for different values of $N$.
- **Step-by-Step Visualization**: See the algorithm try different placements, backtrack, and find the final solution in real-time.
- **Backtracking Logic**: Implements a recursive algorithm to explore all possible configurations.
- **Responsive UI**: Clean and focused interface for educational purposes.
- **Interactive Controls**: Start the visualization with a single click.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/N_Queen/`
3. Open `index.html` in your web browser.
