# Dark Run - Side Scrolling Game

## Description
A thrilling 2D side-scrolling platformer game. "Dark Run" features a dark, atmospheric forest setting where players must run, jump, and dodge obstacles like saws, birds, and monsters to survive. The game uses HTML5 Canvas for dynamic rendering and sprite animation.

## Technologies Used
- HTML5 (Canvas API)
- CSS3 (Game Container Styling)
- JavaScript (Game Loop, Physics, & Sprite Animation)

## Features
- **Dynamic Physics**: Implements gravity, jumping, and collision detection.
- **Sprite Animations**: Features running, jumping, and idle animations for the main character and enemies.
- **Parallax Background**: Multiple background layers (trees, sky) move at different speeds to create a sense of depth.
- **Obstacle Generation**: Procedurally spawns enemies and traps to keep the gameplay challenging.
- **Atmospheric Visuals**: A cohesive dark forest theme using custom image assets.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Scroll Game Dark Run/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Scroll Game Dark Run/
 ├── *.png/*.jpg      # Game assets (sprites, backgrounds, obstacles)
 ├── index.html       # Game canvas container
 ├── main.js          # Core game engine and logic
 └── style.css        # Visual styling
```
