# Breakout Game

## Description
A classic arcade-style Breakout game built for the browser. Players use a paddle to bounce a ball and break all the bricks on the screen. The game features scoring, life management, and increasing difficulty.

## Technologies Used
- HTML5 (Canvas API)
- CSS3
- JavaScript (Game Loop & Collision Detection)

## Features
- **Canvas Rendering**: Uses the HTML5 Canvas API for smooth 2D graphics.
- **Score & Lives**: Tracks the player's progress and provides multiple attempts.
- **Dynamic Bricks**: A grid of colorful bricks that disappear when hit.
- **Keyboard Controls**: Intuitive controls using arrow keys or mouse movement.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Breakout game/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Breakout game/
 ├── index.html       # Game container and canvas
 ├── script.js        # Game logic, physics, and rendering
 └── styles.css       # Layout and UI styling
```
