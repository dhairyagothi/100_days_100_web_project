# 🌿 Plant Website

Plant Website is a modern and responsive landing page designed for showcasing plants, gardening products, and nature-inspired content. The project features an elegant UI, smooth scrolling, and visually appealing sections to create an engaging browsing experience.

---

## ✨ Features

- 🌿 Beautiful landing page
- 🪴 Plant showcase section
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Smooth scrolling and animations
- 🌱 Easy-to-customize layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd PlantWebsite
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code
