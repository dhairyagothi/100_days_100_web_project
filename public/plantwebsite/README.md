# Nature's Corner - Plant Shop

## Description
A modern, single-page application (SPA) style website for a contemporary plant boutique. This project emphasizes sleek design and smooth transitions to create a premium feel for high-end botanical products.

## Technologies Used
- HTML5
- CSS3 (Custom Properties & Responsive Design)
- JavaScript (for scroll-based animations and filtering)

## Features
- **Dynamic Category Filtering**: Browse plants by category with smooth UI updates.
- **Scroll-triggered Animations**: Elements fade and slide into view as the user scrolls.
- **Premium Gallery**: Showcases plants in high-resolution with stylized frames.
- **Contact Integration**: Simple and effective contact form for inquiries.
- **Fully Responsive**: Designed to look great on tablets, phones, and desktops.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/plantwebsite/`
3. Open `plant.html` in your web browser.

## Folder Structure
```text
plantwebsite/
 ├── images/          # Optimized plant assets
 ├── plant.html       # Application structure
 ├── script.js        # Interaction and animation logic
 └── plant.css        # Core styling and theme definitions
```
