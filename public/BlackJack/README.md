# BlackJack Game

## Description
A fully functional, browser-based BlackJack (21) card game. Players can test their luck against the dealer, with features like hitting, standing, and real-time score calculation.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Animations)
- JavaScript (Vanilla)

## Features
- **Interactive Gameplay**: Classic BlackJack rules implemented in JavaScript.
- **Dynamic Score Calculation**: Automatically calculates the value of your hand.
- **Dealer Logic**: AI-controlled dealer that hits and stands according to standard rules.
- **Visual Feedback**: Sound effects and animations for card deals and results.
- **Persistent Stats**: Track wins, losses, and draws during your session.

## Setup Instructions

1. Clone the repository
2. Navigate to the project folder: `public/BlackJack/`
3. Open `blackJ.html` in your web browser.
