# Stone Paper Scissor

## Description
A responsive web project named Stone Paper Scissor. This project demonstrates modern web development techniques and interactive user interface design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- **Responsive Layout**: Adapts to different screen sizes.
- **Interactive UI**: Provides a seamless user experience.
- **Clean Code**: Well-structured and maintainable codebase.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Stone-Paper-Scissor/`
3. Open `index.html` in your web browser.
