# 🔑 Password Reset Form

Password Reset Form is a responsive web application that provides a secure and user-friendly interface for users to reset their account passwords. It demonstrates modern form design, client-side validation, and an intuitive user experience.

---

## ✨ Features

- 🔐 Password reset interface
- 📧 Email input for account verification
- ✅ Client-side form validation
- ⚠️ Error and success feedback
- 📱 Fully responsive design
- 🎨 Clean and modern UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd password-reset-form
```

Run locally

- Open `index.html`
- OR use Live Server in Visual Studio Code

---

## ▶️ Usage

1. Open the application.
2. Enter your registered email address.
3. Submit the form.
4. Receive confirmation or validation feedback.
5. Continue with the password reset process.
