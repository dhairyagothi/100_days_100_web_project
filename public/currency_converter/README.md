# Currency Converter

## Description
A practical utility for converting amounts between different world currencies. It uses real-time exchange rate data to provide accurate conversions, helping users with international travel or financial planning.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Custom Properties)
- JavaScript (Fetch API & Exchange Rate API)

## Features
- **Real-time Conversion**: Fetches current exchange rates from an external API.
- **Multiple Currencies**: Supports a wide range of global currencies.
- **Interactive UI**: Includes country flag icons for easy identification of currencies.
- **Swap Functionality**: Easily swap "From" and "To" currencies with a single click.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/currency_converter/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
currency_converter/
 ├── index.html       # Converter structure
 ├── script.js        # API integration and conversion logic
 └── style.css        # Layout and visual design
```
