# Code Jump Space Game

## Description
A space-themed jumping game inspired by the classic "Doodle Jump". Players control a character jumping on platforms, aiming to reach the highest score possible without falling. The game features moving platforms and increasing difficulty as the player ascends.

## Technologies Used
- HTML5 (Canvas API)
- CSS3
- JavaScript (Physics & Game Logic)

## Features
- **Dynamic Platforms**: Randomly generated platforms that move as the player progresses.
- **Physics Engine**: Implements gravity, jumping velocity, and collision detection.
- **Score Tracking**: Real-time score based on height reached.
- **Space Theme**: Visual assets including a space background and custom character sprites.
- **Interactive Controls**: Move left and right using keyboard input.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/code-jump-space-game/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
code-jump-space-game/
 ├── index.html       # Game container
 ├── script.js        # Game mechanics and physics
 ├── style.css        # Basic layout
 └── *.png            # Game assets (character, platforms, background)
```
