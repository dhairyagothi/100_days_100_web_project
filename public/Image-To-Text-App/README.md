# 🖼️ Image To Text App

Image To Text App is a browser-based Optical Character Recognition (OCR) application that extracts text from images and PDF files. It supports multiple languages, displays OCR confidence, provides text analytics, and includes built-in text-to-speech functionality.

---

## ✨ Features

- 📷 Extract text from images
- 📄 OCR support for PDF files
- 🌍 Multi-language OCR
- 📊 OCR confidence score
- 📈 Word count & character count
- ⏱️ Reading time estimation
- 🔊 Text-to-Speech support
- 🎤 Voice selection
- ⚡ Adjustable speech rate & pitch
- 📥 Download extracted text
- 📋 Copy extracted text
- 🗑️ Clear OCR results
- 📱 Responsive UI

---

## ▶️ Usage

1. Upload an image or PDF.
2. Select the OCR language.
3. Click **Process**.
4. View the extracted text.
5. Copy or download the extracted result.
6. Use Text-to-Speech to listen to the extracted content.
