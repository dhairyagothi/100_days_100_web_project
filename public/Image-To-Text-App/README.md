# Image to Text Conversion App (OCR)

## Description
A powerful Optical Character Recognition (OCR) web application that extracts text from images. Built with Tesseract.js, it allows users to upload images containing text and instantly receive the digitized content, making it easy to copy and reuse text from photos or scans.

## Technologies Used
- HTML5
- Tailwind CSS (for styling and layout)
- JavaScript (Async/Await)
- Tesseract.js (OCR Engine)

## Features
- **Image Upload**: Supports various image formats (JPG, PNG, etc.) via a file input.
- **Real-time OCR**: Processes images locally in the browser to extract text.
- **Image Preview**: Displays a preview of the selected image before and after conversion.
- **Responsive & Modern UI**: Features a glassmorphism design with a vibrant gradient background.
- **Persistent Logs**: Progress tracking during the conversion process.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Image-To-Text-App/`
3. Open `index.html` in your web browser.
4. **Note**: Requires an active internet connection to load the Tesseract.js library from CDN.
