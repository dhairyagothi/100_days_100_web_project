# 🍽️ Restaurant Web Project

Restaurant Web Project is a modern and responsive restaurant landing page designed to showcase a restaurant's menu, services, chefs, and contact information. It provides an elegant user interface suitable for restaurants, cafés, and food businesses.

---

## ✨ Features

- 🍔 Modern restaurant landing page
- 📖 Interactive menu section
- 👨‍🍳 Chef and team showcase
- 🏠 About Us section
- 📞 Contact information
- 📱 Fully responsive design
- 🎨 Attractive UI with smooth animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd restaurant-web-project
```

Run locally

- Open `index.html` in your browser
- OR use Live Server in Visual Studio Code

1. Launch the website.
2. Browse the homepage.
