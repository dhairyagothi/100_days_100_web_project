# Hologram Button

## Description
A futuristic and highly interactive "Hologram" button design. This project showcases advanced CSS techniques to create a button that feels alive, featuring multi-layered animations and glowing effects that respond to user interaction.

## Technologies Used
- HTML5
- CSS3 (Keyframe Animations, Gradients, & Box Shadows)
- JavaScript (for mouse-tracking and hover effects)

## Features
- **3D Depth**: Uses multiple layers and shadows to create a holographic appearance.
- **Dynamic Glow**: Features a pulsating outer glow that intensifies on hover.
- **Micro-interactions**: Subtle shifts in color and scale when the mouse moves over the button.
- **Futuristic Aesthetic**: Combines neon colors and sharp gradients for a sci-fi look.
- **Reusable Component**: Designed to be easily integrated into modern, futuristic web designs.

## Setup Instructions
1. Clone the repository.
2. Navigate to the project folder: `public/Holo Button/`
3. Open `index.html` in your web browser.

## Folder Structure
```text
Holo Button/
 ├── circle.png       # Texture/Asset for the hologram effect
 ├── index.html       # Component structure
 ├── main.js          # Hover interaction logic
 └── style.css        # Core holographic styling
```
